Exact-author delete protocol correction

Contract
- Delete.target_author_aci is optional string extension field 101. Go stores *string; Rust stores Option<String>. Absence and explicit empty are distinct.
- ConversationHandle::send_delete routes exact target_author through build_targeted_delete_content(timestamp, Some(author), optional_channel). Anonymous DM and group production senders also set Some(author); timestamp-only public builder wrappers remain legacy compatibility.
- Standard DM: authenticated sender establishes ServerDm conversation. Present author must parse as current user or sender; absent author means sender only. Exact conversation/type lookup removes only that row; missing targets queue only that admitted author with ServerDm scope. Known targets outside scope are refused. Self-device sender without destination is refused because this route cannot authenticate a destination.
- Anonymous DM: active, unblocked conversation must authenticate sender as its peer. Same optional-author admission applies; exact AnonDm scope/type, one-author tombstone, and legacy peer-only fallback. Inner channel claims are refused.
- Channel and anonymous group controls reject a present author different from authenticated sender, including malformed/empty values, before applying a sender-only mutation. Group mutation additionally requires exact AnonGroup type.
- Explicit empty author is rejected; it never falls back to legacy. No cross-author guessing remains.
- A receiver without support for field 101 still treats a delete as sender-only, so symmetric deletion of peer-authored messages requires both clients to update. Legacy sender deleting its own message remains supported.

Changed flow
Generated Delete schema -> builders -> ConversationHandle/anonymous senders -> DM parse/control dispatch -> DmContent/InboxEvent -> InboxEventProcessor -> exact-author MessageService or AnonDmService -> typed scoped tombstone -> actual deleted author in domain event. Channels validate at control dispatch; groups validate at common anonymous dispatcher and typed storage lookup.
