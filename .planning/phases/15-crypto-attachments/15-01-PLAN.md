**Signal format (from RESEARCH.md):**
- 64-byte random key: [AES key (32)] + [MAC key (32)]
- Ciphertext: IV (16) || AES-CBC(padded plaintext) || HMAC-SHA256 (32)
- Digest: SHA256(entire ciphertext)
- Log-bucketing padding: `max(541, ceil(1.05^ceil(log(size)/log(1.05))))`

**Constants:**
- `IV_LENGTH = 16` (AES block size)
- `AES_KEY_LENGTH = 32` (AES-256)
- `MAC_KEY_LENGTH = 32` (HMAC-SHA256)
- `HMAC_LENGTH = 32` (output size)
- `KEY_SET_LENGTH = 64` (combined key)

**Structs:**
- `EncryptedAttachment { ciphertext: Vec<u8>, key: [u8; 64], digest: [u8; 32], plaintext_size: usize }`

**AttachmentCrypto methods:**
1. `encrypt(plaintext: &[u8]) -> Result<EncryptedAttachment, CryptoError>`:
   - Generate 64-byte random key (rand::rng().fill_bytes)
   - Compute padded_size using log-bucketing formula
   - Pad plaintext with zeros to padded_size
   - Generate 16-byte random IV
   - Encrypt padded plaintext with AES-256-CBC using first 32 bytes of key
   - Compute HMAC-SHA256(IV || ciphertext) using last 32 bytes of key
   - Assemble: IV || encrypted || HMAC
   - Compute digest = SHA256(assembled ciphertext)
   - Return EncryptedAttachment

2. `decrypt(ciphertext: &[u8], key: &[u8; 64], expected_digest: &[u8; 32], plaintext_size: usize) -> Result<Vec<u8>, CryptoError>`:
   - Verify minimum length (IV + 16 + HMAC = 64 bytes minimum)
   - Verify digest first: SHA256(ciphertext) == expected_digest (constant-time)
   - Split ciphertext into IV (16), encrypted (middle), HMAC (32)
   - Verify HMAC: compute HMAC-SHA256(IV || encrypted) with mac_key, constant-time compare
   - If HMAC mismatch, return AttachmentMacMismatch (NOT AttachmentDecryptionFailed - don't reveal which check failed)
   - Decrypt with AES-256-CBC
   - Truncate to plaintext_size (removes padding)
   - Return plaintext

3. `compute_digest(ciphertext: &[u8]) -> [u8; 32]`:
   - SHA256(ciphertext) - utility for callers

4. `padded_size(size: usize) -> usize`:
   - Log-bucketing: `max(541, ceil(1.05^ceil(log(size)/log(1.05))))`
   - Handle size=0 case

**Critical:**
- Use `subtle::ConstantTimeEq` for all comparisons (digest, HMAC)
- HMAC verification BEFORE decryption (verify-then-decrypt)
- Use block_padding::NoPadding since we pad manually with zeros

**Update mod.rs:**

Include doc comments and basic unit tests for round-trip encrypt/decrypt.</action>
