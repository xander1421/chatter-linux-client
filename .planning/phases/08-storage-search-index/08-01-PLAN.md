Create V009SearchIndex migration that:

1. Creates FTS5 virtual table:
```sql
CREATE VIRTUAL TABLE messages_fts USING fts5(
    message_id UNINDEXED,  -- For joining back to messages
    channel_id UNINDEXED,  -- For filtering by channel
    content,               -- Searchable text content
    content='',            -- External content (we manage manually)
    contentless_delete=1   -- Allow DELETE without content
);
```

2. Creates triggers to sync content (extract text from JSON):
- AFTER INSERT trigger: Extract text based on content_type (0, 5, 6 only)
- AFTER UPDATE trigger: Delete old, insert new if content changed
- AFTER DELETE trigger: Delete from FTS

For text extraction, use json_extract on content_json:
- content_type=0 (Text): json_extract(content_json, '$') - the string itself
- content_type=5 (AI): json_extract(content_json, '$.AI.text')
- content_type=6 (Mixed): json_extract(content_json, '$.Mixed.text')

Only insert into FTS when text is not null/empty.

Register in mod.rs: add `pub mod v009_search_index`, `pub use v009_search_index::V009SearchIndex`, and add `.register(V009SearchIndex)` to default_migrations().

```rust
pub struct SearchIndex {
    db: Arc<Database>,
}

impl SearchIndex {
    pub fn new(db: Arc<Database>) -> Self

    /// Search messages by text query.
    /// Returns message IDs with relevance scores, ordered by relevance.
    /// Uses FTS5 MATCH with bm25() ranking.
    pub fn search(
        &self,
        query: &str,
        channel_id: Option<&ChannelId>,  // Filter by channel
        limit: u32,
    ) -> Result<Vec<SearchResult>, StorageError>

    /// Reindex all existing messages (for migration or repair).
    /// Clears FTS table and reinserts from messages table.
    pub fn reindex_all(&self) -> Result<u64, StorageError>
}

/// Search result with message ID and relevance score.
pub struct SearchResult {
    pub message_id: MessageId,
    pub channel_id: ChannelId,
    pub score: f64,  // bm25 score (lower is better match)
}
```

Implementation notes:
- Search query: Use FTS5 MATCH operator with bm25() for ranking
- Channel filter: AND channel_id = ?2 if provided
- Escape query for FTS5 (quote special chars)
- reindex_all: DELETE FROM messages_fts, then INSERT ... SELECT from messages
- Use while loop pattern for collecting results (see message_repo.rs)
