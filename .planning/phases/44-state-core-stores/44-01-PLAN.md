Implement the generic Store<T> with:

```rust
use std::sync::Arc;
use parking_lot::RwLock;
use tokio::sync::broadcast;

/// Reactive state container with subscription support.
pub struct Store<T: Clone + Send + Sync + 'static> {
    state: Arc<RwLock<T>>,
    sender: broadcast::Sender<T>,
}
```

Methods:
- `new(initial: T) -> Self` - Create store with initial state, broadcast capacity 16
- `get(&self) -> T` - Clone current state
- `set(&self, value: T)` - Replace state and broadcast to subscribers
- `update(&self, f: impl FnOnce(&mut T))` - Update in place and broadcast
- `subscribe(&self) -> broadcast::Receiver<T>` - Get receiver for updates

Use parking_lot::RwLock for sync access (same as auth_interceptor pattern). Broadcast capacity 16 is sufficient for UI subscribers.
