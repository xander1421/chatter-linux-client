<task type="auto">
  <name>Task 1: Create V010 key store migration</name>
  <files>src/storage/migrations/v010_key_store.rs, src/storage/migrations/mod.rs</files>
  <action>
Create V010KeyStore migration with these tables:

1. `local_identity` - Single row for local device identity:
   - `id` INTEGER PRIMARY KEY (always 1, enforced by CHECK)
   - `registration_id` INTEGER NOT NULL (Signal registration ID, u32)
   - `identity_key_pair` BLOB NOT NULL (serialized IdentityKeyPair)
   - `created_at` TEXT NOT NULL

2. `remote_identities` - Known remote identity keys (TOFU):
   - `address` TEXT PRIMARY KEY (ProtocolAddress as "name:device_id")
   - `identity_key` BLOB NOT NULL (serialized IdentityKey, 33 bytes)
   - `first_seen_at` TEXT NOT NULL
   - `updated_at` TEXT NOT NULL

3. `prekeys` - One-time pre-keys:
   - `id` INTEGER PRIMARY KEY (PreKeyId)
   - `record` BLOB NOT NULL (serialized PreKeyRecord)
   - `created_at` TEXT NOT NULL

4. `signed_prekeys` - Signed pre-keys:
   - `id` INTEGER PRIMARY KEY (SignedPreKeyId)
   - `record` BLOB NOT NULL (serialized SignedPreKeyRecord)
   - `created_at` TEXT NOT NULL

5. `kyber_prekeys` - Post-quantum Kyber pre-keys:
   - `id` INTEGER PRIMARY KEY (KyberPreKeyId)
   - `record` BLOB NOT NULL (serialized KyberPreKeyRecord)
   - `created_at` TEXT NOT NULL

6. `kyber_prekey_usage` - Track Kyber key reuse (for last-resort key protection):
   - `kyber_prekey_id` INTEGER NOT NULL
   - `ec_prekey_id` INTEGER NOT NULL
   - `base_key` BLOB NOT NULL (PublicKey, 33 bytes)
   - `used_at` TEXT NOT NULL
   - PRIMARY KEY (kyber_prekey_id, ec_prekey_id, base_key)
   - FOREIGN KEY (kyber_prekey_id) REFERENCES kyber_prekeys(id)

7. `sessions` - Double Ratchet session records:
   - `address` TEXT PRIMARY KEY (ProtocolAddress as "name:device_id")
   - `record` BLOB NOT NULL (serialized SessionRecord)
   - `updated_at` TEXT NOT NULL

8. `sender_keys` - Group sender key records:
   - `sender` TEXT NOT NULL (ProtocolAddress)
   - `distribution_id` TEXT NOT NULL (UUID as string)
   - `record` BLOB NOT NULL (serialized SenderKeyRecord)
   - `updated_at` TEXT NOT NULL
   - PRIMARY KEY (sender, distribution_id)

Register V010KeyStore in default_migrations().
Use BLOB for all serialized crypto data (not JSON - binary efficiency matters for keys).
  </action>
