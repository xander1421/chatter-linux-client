5. Update users table: `UPDATE users SET registration_lock = $1, svr_public_key = $2 WHERE id = $3`
6. Commit transaction

Use `r.pool.Begin(ctx)` for the transaction. Always `defer tx.Rollback(ctx)` and call `tx.Commit(ctx)` at the end.
