Replace the stub AISummarizeService with an implementation for conversation summarization.

**Summarization approach:**
The backend IntegrationService handles AI calls. The client's role is to:
1. Fetch messages for a channel/thread
2. Send them to an AI integration for summarization
3. The AI responds via the integration event stream

**AISummarizeService implementation:**

**Error enum (SummarizeError):**
- NotLoggedIn
- Network(NetworkError)
- NoIntegrationConfigured - channel has no AI integration
- SummarizationFailed(String)

**Dependencies:**
- Arc<SettingsRepository> for auth
- AIService reference (for integration queries)

**Methods:**

1. `current_user_id()` - private helper

2. `get_channel_ai_integration(&self, ai_service: &AIService, client: &mut IntegrationClient, channel_id: &str) -> Result<Option<Integration>, SummarizeError>`
   - Get channel integrations
   - Filter for AI types (Claude, OpenAI, GoogleAi, etc.)
   - Return first active AI integration or None

3. `is_ai_integration_type(integration_type: i32) -> bool`
   - Helper to check if type is 10-15 (AI provider range)

4. `prepare_summarization_prompt(messages: &[Message], instruction: Option<&str>) -> String`
   - Build a summarization prompt from messages
   - Default instruction: "Summarize the following conversation concisely"
   - Format: instruction + newline + messages (author: content format)

5. `request_summary(&self, ai_service: &AIService, client: &mut IntegrationClient, channel_id: &str, messages: &[crate::proto::chat_v1::Message], instruction: Option<&str>) -> Result<(), SummarizeError>`
   - Check logged in
   - Get channel's AI integration (error if none)
   - Build prompt via prepare_summarization_prompt
   - The actual summary request goes through MessageService.send_message with targets_ai_bot=true
   - This method validates prerequisites; actual send is done by caller via message service
   - Return Ok(()) if prerequisites met, error otherwise

**Note:** The actual summarization flow is:
1. UI/service calls request_summary to validate channel has AI
2. UI sends a message with targets_ai_bot=true containing the prompt
3. AI integration receives it and responds via streaming events
4. The response comes back as an AIBotContent message

**Update mod.rs:**
- Add re-exports for AIService and AIError
- Add re-exports for AISummarizeService and SummarizeError
