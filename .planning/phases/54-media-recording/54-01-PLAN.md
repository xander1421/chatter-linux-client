<task type="auto">
  <name>Task 2: Implement AudioRecorder with cpal/hound</name>
  <files>src/media/audio_recorder.rs, src/error/media_error.rs</files>
  <action>
Implement AudioRecorder for voice message recording:

1. Add RecordingState enum:
   - Idle (not recording)
   - Recording { started_at: Instant, samples: Vec<f32> }
   - Stopped { samples: Vec<f32>, duration: Duration }

2. Add RecordingError variant to MediaError (device not found, permission denied, encoding failed)

3. Implement AudioRecorder struct:
   - stream: Option<cpal::Stream> (must be kept alive during recording)
   - state: RecordingState
   - sample_rate: u32 (capture device sample rate)
   - channels: u16 (capture device channels)

4. Implement methods:
   - new() -> Result<Self, MediaError>: Initialize, list input devices, select default
   - start() -> Result<(), MediaError>: Begin recording, create input stream with callback that pushes samples to buffer
   - stop() -> Result<Duration, MediaError>: Stop recording, return duration
   - save(&self, path: &Path) -> Result<(), MediaError>: Encode samples to WAV using hound
   - cancel(): Discard recording, return to Idle state
   - state(&self) -> &RecordingState: Get current state
   - duration(&self) -> Option<Duration>: Get elapsed time if recording

5. Recording callback pattern:
   - Use Arc<Mutex<Vec<f32>>> for sample buffer shared between callback and struct
   - Callback pushes samples to buffer
   - stop() takes ownership of buffer

6. WAV encoding:
   - Use hound::WavWriter with spec: channels, sample_rate, bits_per_sample=16
   - Convert f32 samples to i16 (multiply by i16::MAX)

Use cpal's default input device. Handle error cases:
- No input device available
- Stream creation fails
- Permission denied (return appropriate error, don't panic)
  </action>
  <verify>cargo check compiles, AudioRecorder can be instantiated</verify>
  <done>AudioRecorder with start/stop/save/cancel methods using cpal for input and hound for WAV encoding</done>
</task>
