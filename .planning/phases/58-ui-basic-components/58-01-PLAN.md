  <files>ui/components/button.slint</files>
  <action>
Rewrite Button component with full features:
- `in property <string> text` - button label
- `in property <string> variant` - "primary", "secondary", "ghost", "danger"
- `in property <bool> disabled` - prevents interaction
- `in property <bool> loading` - shows loading spinner
- `in property <image> icon` - optional leading icon
- `callback clicked()`

Implementation:
- Use states for hover/pressed: track `hover` and `pressed` bools
- TouchArea sets hover via pointer-event, pressed via mouse-down
- Background colors by variant:
  - primary: Colors.primary, hover: Colors.primary-hover, active: Colors.primary-active
  - secondary: Colors.surface, hover: Colors.surface-hover
  - ghost: transparent, hover: rgba surface with 10% opacity
  - danger: Colors.error, hover: darker red
- Text color: Colors.text-primary for all
- Disabled: opacity 0.5, no hover effects
- Loading: show spinning indicator (Rectangle with rotating border), hide text
- Icon: if icon.width > 0, show 16x16 Image before text with Spacing.sm gap
- min-height: 36px, padding: Spacing.md horizontal
- border-radius: Spacing.radius-md
  </action>
