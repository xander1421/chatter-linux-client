**Architecture from ARCHITECTURE.md:**
- When member joins, send our mailbox ID via their device inbox (sealed sender)
- Wait for their mailbox ID asynchronously (handled by inbox handlers)
- Mailbox exchange message includes group_id and mailbox_address

**Pattern from DM bootstrap:**
- DmBootstrap.initiate_dm() creates mailbox and sends via sealed sender
- handle_incoming_bootstrap() processes peer's bootstrap message
- Token consumed after successful mailbox creation

```rust
use std::sync::Arc;
use chrono::{DateTime, Duration, Utc};
use crate::domain::{ChannelId, UserId};
use crate::error::MailboxError;
use crate::mailbox::{TokenManager, GroupMailboxManager, GroupMailbox};

/// Default TTL for group mailboxes (7 days).
pub const DEFAULT_GROUP_MAILBOX_TTL_SECONDS: u64 = 7 * 24 * 60 * 60;

/// Group mailbox exchange message (sent via device inbox).
#[derive(Clone, Debug)]
pub struct GroupMailboxExchange {
    /// The group this mailbox is for.
    pub group_id: ChannelId,
    /// The sender's mailbox public key (32 bytes Ed25519).
    pub mailbox_public_key: [u8; 32],
    /// When this mailbox expires (optional hint).
    pub expires_at: Option<DateTime<Utc>>,
}

/// Result of initiating our mailbox for a group.
pub struct GroupMailboxInit {
    /// Our newly created mailbox.
    pub mailbox: GroupMailbox,
    /// Exchange message to send to group members.
    pub exchange: GroupMailboxExchange,
}

/// Result of handling an incoming mailbox exchange.
pub struct ExchangeResult {
    /// The member who sent their mailbox.
    pub user_id: UserId,
    /// The group this is for.
    pub group_id: ChannelId,
    /// Whether this is a new mailbox (vs update).
    pub is_new: bool,
}
```

These types define the protocol for mailbox exchange between group members.

Methods:

1. `new(token_manager, mailbox_manager) -> Self`

2. `get_or_create_mailbox(&self, group_id: &ChannelId) -> Result<GroupMailboxInit, MailboxError>`
   - Check if we already have a mailbox for this group
   - If exists and not expired, return existing with exchange message
   - If not exists or expired:
     a. Get available token from TokenManager
     b. Generate Ed25519 keypair
     c. Create mailbox on server (via MailboxClient later, for now prepare)
     d. Save to database
     e. Return GroupMailboxInit with exchange message
   - Mark token as used after successful creation

3. `prepare_exchanges_for_members(&self, group_id: &ChannelId, member_ids: &[UserId]) -> Result<Vec<(UserId, GroupMailboxExchange)>, MailboxError>`
   - Get or create our mailbox
   - Return list of (member_id, exchange) tuples for sending
   - Caller sends via sealed sender to each member's device inbox

4. `refresh_mailbox_if_needed(&self, group_id: &ChannelId) -> Result<Option<GroupMailboxInit>, MailboxError>`
   - Check if our mailbox expires within 24 hours
   - If so, create new mailbox (keeping old for overlap)
   - Return new exchange to send to members

Follow DmBootstrap pattern for token consumption and key generation.
Use same rand::fill() pattern for Ed25519 key generation (avoid rand_core conflicts).
