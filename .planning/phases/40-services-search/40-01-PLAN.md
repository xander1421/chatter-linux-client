- MessageRepository for fetching full messages by ID

**Established patterns:**
- Service takes Arc<Repository> dependencies
- current_user_id() from settings for auth check
- Server-first fetch with local upsert
- Error enum with NotLoggedIn, Network, Storage variants

**Constraining decisions:**
- Semantic search out of scope for v1 (see PROJECT.md)
- Search results can be fetched fresh from server (discovery pattern)

<task type="auto">
  <name>Task 2: Add server search and combined search methods</name>
  <files>src/services/search_service.rs</files>
  <action>
Add server and combined search functionality:

1. Implement server search:
   - search_server(client, channel_id, query, author_id, start_time, end_time, limit, offset) -> Result<Vec<Message>, SearchError>
     * Requires current_user_id() (must be authenticated to query server)
     * Calls message_client.search() with parameters
     * Converts proto Message to domain Message using proto_to_domain_message helper
     * Does NOT store results locally (same pattern as channel search - discovery, not ownership)

2. Add proto_to_domain_message helper function:
   - Takes &chat_v1::Message, returns Result<Message, SearchError>
   - Parse IDs from strings (message_id, channel_id, sender_id as Option)
   - Map content_type enum to domain MessageContent
   - Parse timestamps from millis using chrono (timestamp_millis_opt with fallback to epoch)
   - Map reaction counts to domain ReactionCount vec
   - Handle thread_id, edited_at, deleted_at as Option

3. Implement combined search:
   - search_combined(client, query, channel_id, limit) -> Result<CombinedSearchResults, SearchError>
     * First try local search (does not require auth)
     * If authenticated, also fetch from server with same query
     * Return CombinedSearchResults struct containing:
       - local_results: Vec<SearchResult>
       - server_results: Vec<Message>
       - local_count: usize
       - server_count: usize
     * If server call fails (not logged in or network error), return local results only with empty server_results

4. Create CombinedSearchResults struct (public, Debug, Clone):
   - local_results: Vec<SearchResult>
   - server_results: Vec<Message>
   - local_count: usize
   - server_count: usize
