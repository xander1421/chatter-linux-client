<task type="auto">
  <name>Task 1: Implement UserState for user/profile caching</name>
  <files>src/state/user_state.rs</files>
  <action>
Replace the stub UserState with a full implementation wrapping Store<UserStateData>.

UserStateData should contain:
- users: HashMap<UserId, User> for user entity cache
- profiles: HashMap<UserId, Profile> for profile cache
- friends: Vec<UserId> for friend list (IDs only, profiles fetched separately)
- blocked_users: HashSet<UserId> for blocked user tracking
- current_user_profile: Option<Profile> for logged-in user's own profile

UserState methods:
- new() -> Self
- get() -> UserStateData
- subscribe() -> broadcast::Receiver<UserStateData>
- set_user(user: User) - adds/updates user in cache
- set_profile(profile: Profile) - adds/updates profile in cache
- get_user(user_id: &UserId) -> Option<User> - direct lookup
- get_profile(user_id: &UserId) -> Option<Profile> - direct lookup
- set_friends(friends: Vec<UserId>) - replace friend list
- add_friend(user_id: UserId) - add to friend list (if not present)
- remove_friend(user_id: &UserId) - remove from friend list
- set_blocked(blocked: HashSet<UserId>) - replace blocked set
- block_user(user_id: UserId) - add to blocked set
- unblock_user(user_id: &UserId) - remove from blocked set
- is_blocked(user_id: &UserId) -> bool - check if blocked
- set_current_user_profile(profile: Profile) - set own profile
- clear() - clear all caches (for logout)

Follow the pattern from AuthState: wrap Store<UserStateData>, expose method-based API.
  </action>
  <verify>cargo build --lib 2>&1 | head -20</verify>
  <done>UserState compiles with Store<T> wrapper and all methods</done>
</task>

- is_online(user_id: &UserId) -> bool - convenience check (matches PresenceStatus::Online)

- clear() - clear all presence (for logout/disconnect)
