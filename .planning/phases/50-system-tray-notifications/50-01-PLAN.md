<task type="auto">
  <name>Task 2: Implement SystemTray with ksni</name>
  <files>src/system/tray.rs, src/error/system_error.rs</files>
  <action>
Implement SystemTray using ksni (StatusNotifierItem protocol):

1. Add SystemError variant:
   - TrayInit(String) - failed to initialize tray

2. Create TrayMessage enum for communication:
   - SetUnreadCount(u32) - update badge
   - SetStatus(TrayStatus) - online/offline/away
   - Quit - signal app quit

3. Create TrayStatus enum:
   - Online, Offline, Away, DoNotDisturb

4. Implement SystemTray struct with:
   - sender: tokio::sync::mpsc::Sender<TrayMessage>
   - spawn() -> Result<(Self, TrayHandle), SystemError> - spawn tray service
   - set_unread_count(&self, count: u32) - send unread badge update
   - set_status(&self, status: TrayStatus) - update status
   - quit(&self) - send quit signal

5. Implement ksni::Tray trait for internal TrayService:
   - id() -> "chatter-linux"
   - title() -> "Chatter"
   - icon_name() -> icon based on status/unread (chatter-linux or chatter-linux-unread or dialog-information)
   - menu() -> Vec with: "Open Chatter", separator, "Quit"
   - activate() -> open main window (send OpenWindow message)

6. TrayHandle wraps JoinHandle for cleanup:
   - shutdown() -> signals quit and awaits join

Use tokio::sync::mpsc channel (capacity 16) for communication.
Icon names use XDG icon theme conventions. If custom icons don't exist, fall back to generic ones.
  </action>

  <done>SystemTray shows icon with menu, supports unread badge and status updates</done>
