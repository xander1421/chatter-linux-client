**Established patterns:**
- CallWorkerHandle uses command enum dispatched to dedicated thread (non-Send LiveKit types)
- Signal actor pattern: `actor.complete_call_key_exchange()` does ECDH + identity lookup + HKDF
- EphemeralCallKey with ZeroizeOnDrop for key material
- CallSignalingService sends offer/answer via sealed sender DM

**Constraining decisions:**
- No new service — extend existing CallWorkerHandle + CallSignalingService
- Crypto stays in crypto/ (call_key_provider.rs, signal/actor.rs) — only orchestration moves
- PendingOutgoingCall moves from UI thread_local to core
- Return types must give UI enough data to display (call_id, verification emojis, is_video)

   - `pending_dm_call: Arc<Mutex<Option<PendingDmCall>>>` field
   - `set_pending_dm_call()`, `take_pending_dm_call()` methods

3. Add `start_dm_call()` to CallSignalingService:
   ```
   pub async fn start_dm_call(&self, peer_id: &UserId, channel_id: ChannelId, call_type: CallType, call_worker: &CallWorkerHandle, user_id: UserId) -> Result<CallId, CallSignalingError>
   ```
   This method:
   - Generates EphemeralCallKey
   - Calls call_worker.initiate_call() with placeholder key [0u8;32]
   - Sends offer via send_call_offer() with ephemeral public key
   - Stores PendingDmCall in pending state
   - Returns call_id

4. Add `complete_dm_call()` to CallSignalingService:
   ```
   pub async fn complete_dm_call(&self, peer_ephemeral_pk: [u8; 32], call_id: &str, peer_id: &UserId, signal_service: &SignalService, call_worker: &CallWorkerHandle) -> Result<CallSetupResult, CallSignalingError>
   ```
   This method:
   - Takes pending call via take_pending_dm_call()
   - Validates call_id matches
   - Calls signal_service.actor.complete_call_key_exchange(our_priv, peer_pub, peer_id, call_id, true)
   - Calls call_worker.set_encryption_key(derived_key)
   - Derives verification emojis via CallVerification::derive_verification_emojis()
   - Returns CallSetupResult
   - Ephemeral key is dropped (zeroized) after use

5. Add `accept_dm_call()` to CallSignalingService:
   ```
   pub async fn accept_dm_call(&self, caller_ephemeral_pk: [u8; 32], call_id: &str, caller_id: &UserId, signal_service: &SignalService, call_worker: &CallWorkerHandle, user_id: UserId) -> Result<CallSetupResult, CallSignalingError>
   ```
   This method:
   - Generates EphemeralCallKey
   - Calls signal_service.actor.complete_call_key_exchange(our_priv, caller_pub, caller_id, call_id, false)
   - Sends answer via send_call_answer() with our ephemeral public key
   - Calls call_worker.join_call() with derived key
   - Derives verification emojis
   - Drops ephemeral key (zeroized)
   - Returns CallSetupResult

Add appropriate error variants to CallSignalingError for: NoPendingCall, CallIdMismatch, KeyDerivationFailed.

Do NOT change any existing methods. Only add new ones.
