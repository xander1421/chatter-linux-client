```rust
pub async fn edit_message(
    &self,
    message_client: &mut MessageClient,
    channel_id: &ChannelId,
    message_id: &MessageId,
    new_text: &str,
) -> Result<Message, MessageError>
```

Implementation:
1. Check logged in via `current_user_id()?`
2. Validate new_text.trim() is not empty → MessageError::InvalidContent
3. Get existing message from local DB via `message_repo.get(message_id)?`
   - If None → MessageError::MessageNotFound(message_id.clone())
4. Verify sender_id matches current user → MessageError::NotAuthor (only if sender_id.is_some())
5. Build proto content: `Content { type: Some(Type::Text(new_text.to_string())) }`
6. Call `message_client.edit_message(message_id.to_string(), channel_id.to_string(), content).await?`
7. Convert proto response to domain using proto_to_domain_message()
8. Update local message:
   - Mark edited via `message.mark_edited()`
   - Update content
   - Call `message_repo.update(&updated_message)?`
9. Return updated message

Note: Server returns the edited Message proto. Use that to update local state for consistency.

<task type="auto">
  <name>Task 3: Implement get_messages operation</name>
  <files>src/services/message_service.rs</files>
  <action>
Add get_messages method to MessageService:

```rust
pub async fn get_messages(
    &self,
    message_client: &mut MessageClient,
    channel_id: &ChannelId,
    limit: u32,
    before: Option<&MessageId>,
) -> Result<Vec<Message>, MessageError>
```

Implementation:
1. Check logged in via `current_user_id()?`
2. First try local cache: `message_repo.list_for_channel(channel_id, before, limit)?`
3. If local has enough messages (>= limit), return them
4. If local is sparse, fetch from server:
   - Build reference_message_id from `before`
   - Call `message_client.get_messages()` with:
     - channel_id.to_string()
     - limit as i32
     - thread_root_id = None
     - page_token = None (we use cursor instead)
     - sort_direction = MessageSortDirection::SortNewestFirst
     - reference_message_id = before.map(|id| id.to_string())
     - reference_time = None
5. Convert proto messages to domain messages
6. For each server message not in local DB, insert via `message_repo.insert()`
   - Use upsert pattern: try insert, on conflict update
7. Return the converted messages

Note: This is a hybrid fetch - prefer local cache, backfill from server. For v1, always fetch from server to ensure freshness. Local cache is for offline access.

Simpler v1 approach:
- Always fetch from server
- Store/update all returned messages locally
- Return the converted messages
