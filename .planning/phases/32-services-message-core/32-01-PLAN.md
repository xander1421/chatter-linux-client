<task type="auto">
  <name>Task 2: Implement send_message operation</name>
  <files>src/services/message_service.rs</files>
  <action>
Add send_message method to MessageService:

```rust
pub async fn send_message(
    &self,
    message_client: &mut MessageClient,
    channel_id: &ChannelId,
    text: &str,
    attachment_ids: Vec<AttachmentId>,
    thread_id: Option<&MessageId>,
    mentioned_integrations: Vec<IntegrationId>,
    targets_ai_bot: bool,
) -> Result<Message, MessageError>
```

Implementation steps:
1. Check logged in via `current_user_id()?`
2. Validate content - text.trim() must not be empty OR attachment_ids must not be empty
3. Build proto content:
   - If text only: `Content { type: Some(Type::Text(text.to_string())) }`
   - If attachments only or mixed: Use Type::Text for now (attachments handled separately)
4. Call `message_client.send_message()` with:
   - channel_id.to_string()
   - content
   - parent_id = thread_id.map(|id| id.to_string()) for threading
   - ephemeral = false (ephemeral is Phase 34)
   - ephemeral_ttl = None
   - encrypt = false (encryption is a separate concern for now)
   - crypto_options = None
   - mentioned_integrations.iter().map(|id| id.to_string()).collect()
   - targets_ai_bot
   - mentioned_file_ids = attachment_ids.iter().map(|id| id.to_string()).collect()
5. Convert proto Message to domain Message using `proto_to_domain_message()` helper
6. Store in local DB via `message_repo.insert(&message)?`
7. Return the domain message

Helper function `proto_to_domain_message(proto: &chat_v1::Message, sender_id: UserId) -> Result<Message, MessageError>`:
- Parse IDs from proto strings
- Map proto content to MessageContent enum
- Map reaction_counts
- Convert timestamps (proto uses millis, domain uses DateTime<Utc>)
- Set sender_id from parameter (we know who sent it)

Note: The proto Message type is `crate::proto::chat_v1::Message`.
