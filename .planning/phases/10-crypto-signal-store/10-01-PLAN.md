```rust
fn storage_to_signal_error(e: StorageError) -> SignalProtocolError {
    SignalProtocolError::ApplicationCallbackError("storage", Box::new(e))
}
```

3. Implement IdentityKeyStore:
- get_identity_key_pair: Deserialize IdentityKeyPair from key_store.get_local_identity()
- get_local_registration_id: Return registration_id from get_local_identity()
- save_identity: Use key_store.save_identity(), return IdentityChange based on key_changed bool
- is_trusted_identity: TOFU - if no stored key, trust. If stored, compare.
- get_identity: Deserialize IdentityKey from key_store.get_identity()

4. Implement PreKeyStore:
- get_pre_key: Deserialize PreKeyRecord from key_store.get_prekey()
- save_pre_key: Serialize and call key_store.save_prekey()
- remove_pre_key: Call key_store.remove_prekey()

5. Implement SignedPreKeyStore:
- get_signed_pre_key: Deserialize SignedPreKeyRecord from key_store.get_signed_prekey()
- save_signed_pre_key: Serialize and call key_store.save_signed_prekey()

6. Implement KyberPreKeyStore:
- get_kyber_pre_key: Deserialize KyberPreKeyRecord from key_store.get_kyber_prekey()
- save_kyber_pre_key: Serialize and call key_store.save_kyber_prekey()
- mark_kyber_pre_key_used: Call key_store.mark_kyber_prekey_used() with base_key.serialize()

7. Implement SessionStore:
- load_session: Deserialize SessionRecord from key_store.load_session()
- store_session: Serialize and call key_store.store_session()

8. Implement SenderKeyStore:
- load_sender_key: Deserialize SenderKeyRecord from key_store.load_sender_key()

9. Implement ProtocolStore trait (empty impl, just marker)
