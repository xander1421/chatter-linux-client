<task type="auto">
  <name>Task 2: Implement login flow</name>
  <files>src/services/auth_service.rs</files>
  <action>
Implement login orchestration:

1. `AuthService::login(&self, auth_client: &mut AuthClient, username: &str, password: &str, device_info: &str) -> Result<LoginResult, AuthError>`:

   a. Check not already logged in (return AlreadyLoggedIn if so)

   b. Hash password using Argon2id (or SHA256 as placeholder - match backend):
      - For now, use SHA256 hash (backend may expect pre-hashed)
      - `let password_hash = Sha256::digest(password.as_bytes());`

   c. Get or generate identity:
      - If identity_manager.has_identity() returns true, get existing
      - Otherwise generate new identity (for new device)

   d. Generate device credentials:
      - `DeviceCredentials::generate(device_id, &profile_key)`
      - For first login, device_id might come from server response

   e. Call auth_client.login():
      - username, password_hash, device_info
      - public_key from identity
      - device_auth_token from credentials
      - unidentified_access_key from credentials
      - device_id: None for new device, Some(id) for re-auth

   f. On success:
      - Store user_id in settings_repo (CURRENT_USER_ID)
      - Store device_id in settings_repo (CURRENT_DEVICE_ID)
      - Configure auth_interceptor with Basic auth:
        `auth_interceptor.set_basic(credentials.auth_username(&user_id), credentials.auth_token_base64())`
      - Store user in user_repo
      - Return LoginResult with user info

   g. On error: Map to AuthError

2. LoginResult struct:
   - user_id: UserId
   - device_id: u32
   - display_name: String
   - needs_prekey_upload: bool (if new device)

Use `sha2` crate for SHA256.
  </action>
  <verify>cargo check --lib passes</verify>
  <done>Login flow orchestrates crypto → network → storage → auth configuration</done>
</task>

<task type="auto">
  <name>Task 3: Implement registration and logout flows</name>
  <files>src/services/auth_service.rs</files>
  <action>
1. `AuthService::register(&self, auth_client: &mut AuthClient, username: &str, password: &str, display_name: &str, device_info: &str) -> Result<LoginResult, AuthError>`:

   a. Check not already logged in

   b. Generate new identity (always new for registration):
      - `identity_manager.generate_identity(&mut OsRng)`
      - Get registration_id and identity_key_pair

   c. Generate initial prekeys:
      - signed_prekey via prekey_manager
      - kyber_prekey via prekey_manager
      - 100 one-time prekeys via prekey_manager

   d. Generate device credentials with device_id=1 (primary device):
      - Generate 32-byte profile_key randomly
      - DeviceCredentials::generate(1, &profile_key)

   e. Hash password (SHA256 for now)

   f. Call auth_client.register_and_wait():
      - Include all crypto material
      - Wait for completion

   g. On success (Session returned):
      - Store user_id, device_id in settings
      - Configure auth_interceptor
      - Store user in user_repo
      - Return LoginResult with needs_prekey_upload=false (already uploaded)

2. `AuthService::logout(&self, auth_client: &mut AuthClient) -> Result<(), AuthError>`:

   a. Check is logged in (return NotLoggedIn if not)

   b. Get current device_id from settings

   c. Call auth_client.logout(device_id)

   d. Clear auth_interceptor

   e. Remove CURRENT_USER_ID and CURRENT_DEVICE_ID from settings

   f. Return Ok(())

   Note: Do NOT clear identity keys - they should persist for potential re-login

3. Add re-exports in services/mod.rs if needed
  </action>

  <done>Registration generates full crypto suite, logout clears auth state</done>
