   - Derive 16-byte UAK from profile key using HKDF-SHA256 with info="UnidentifiedDelivery"
   - Return new DeviceCredentials

   - Reconstruct from stored values (after login response)

4. `DeviceCredentials::auth_username(&self, user_id: &str) -> String`:
   - Format: "{user_id}.{device_id}" for Basic auth header

5. `DeviceCredentials::auth_token_base64(&self) -> String`:
   - Return base64-encoded auth token for transmission

6. `DeviceToken` struct (separate type for token alone):
   - `token: [u8; 32]`
   - `DeviceToken::generate() -> Self`
   - `DeviceToken::from_bytes(bytes: &[u8]) -> Result<Self, CryptoError>`
   - `DeviceToken::as_bytes(&self) -> &[u8; 32]`
   - `DeviceToken::to_base64(&self) -> String`

Use `hkdf` crate for HKDF-SHA256. Use `rand::rngs::OsRng` for secure random.

  <action>
Add UAK-specific functionality:

1. `derive_uak(profile_key: &[u8; 32]) -> [u8; 16]`:
   - HKDF-SHA256 with salt=None, ikm=profile_key, info=b"UnidentifiedDelivery"
