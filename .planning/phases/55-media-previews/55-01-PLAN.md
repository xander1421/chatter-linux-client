  <name>Task 3: Implement CodePreview with syntect syntax highlighting</name>
  <files>src/media/code_preview.rs</files>
  <action>
Replace stub with full implementation using syntect.

CodePreview struct should provide:
- `new() -> Self` - Initialize with default syntax set and theme
- `highlight(code: &str, language: &str) -> Result<Vec<HighlightedLine>, MediaError>` - Syntax highlight code
- `highlight_file(path: &Path) -> Result<Vec<HighlightedLine>, MediaError>` - Highlight file (detect language from extension)
- `detect_language(path: &Path) -> Option<String>` - Get language name from file extension
- `supported_extensions() -> &'static [&'static str]` - List supported file extensions

HighlightedLine struct:
```rust
pub struct HighlightedLine {
    pub line_number: usize,
    pub segments: Vec<HighlightedSegment>,
}

pub struct HighlightedSegment {
    pub text: String,
    pub style: SegmentStyle,
}

pub struct SegmentStyle {
    pub foreground: (u8, u8, u8),  // RGB
    pub bold: bool,
    pub italic: bool,
    pub underline: bool,
}
```

Use syntect's:
- `SyntaxSet::load_defaults_newlines()` for syntax definitions
- `ThemeSet::load_defaults()` for themes
- Use "base16-ocean.dark" theme (matches dark-only UI constraint)
- `HighlightLines` for stateful line-by-line highlighting

Handle unknown languages gracefully (return plain text, no error).

Do NOT store SyntaxSet/ThemeSet in struct (large, use lazy_static or recreate).
Use `once_cell::sync::Lazy` for static initialization of syntax/theme sets.
  </action>
  <verify>cargo check --lib compiles, CodePreview methods are public</verify>
  <done>CodePreview with highlight(), highlight_file(), detect_language(), supported_extensions()</done>
