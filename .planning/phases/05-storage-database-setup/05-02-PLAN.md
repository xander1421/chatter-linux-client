<task type="auto">
  <name>Task 1: Create Migration trait and MigrationRunner</name>
  <files>src/storage/migrations/mod.rs</files>
  <action>
Implement migration infrastructure in src/storage/migrations/mod.rs:

1. Define Migration trait:
```rust
pub trait Migration {
    /// Unique version number (e.g., 1, 2, 3...)
    fn version(&self) -> u32;

    /// Human-readable description
    fn description(&self) -> &'static str;

    /// SQL to apply this migration (can be multiple statements)
    fn up(&self) -> &'static str;

    /// SQL to revert this migration (optional, for rollback)
    fn down(&self) -> Option<&'static str> { None }
}
```

2. Implement MigrationRunner:
```rust
pub struct MigrationRunner {
    migrations: Vec<Box<dyn Migration>>,
}
```

Methods:
- `MigrationRunner::new() -> Self` - Create empty runner
- `MigrationRunner::register(mut self, migration: impl Migration + 'static) -> Self` - Builder pattern to add migrations
- `MigrationRunner::run(&self, conn: &Connection) -> Result<(), StorageError>` - Execute pending migrations

Run logic:
1. Create schema_version table if not exists:
   ```sql
   CREATE TABLE IF NOT EXISTS schema_version (
       version INTEGER PRIMARY KEY,
       description TEXT NOT NULL,
       applied_at TEXT NOT NULL
   )
   ```
2. Get current version: `SELECT MAX(version) FROM schema_version`
3. Sort migrations by version
4. For each migration where version > current:
   - Execute up() SQL in a transaction
   - Insert record into schema_version
   - Log migration applied
5. Return Ok(()) or first error

Use rusqlite::Connection directly (not Database wrapper) since migrations run before full initialization.
