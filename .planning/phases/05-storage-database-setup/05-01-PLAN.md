<task type="auto">
  <name>Task 2: Implement Database struct with SQLCipher connection pool</name>
  <files>src/storage/database.rs</files>
  <action>
Implement the Database struct following ARCHITECTURE.md pattern:

```rust
use rusqlite::{Connection, OpenFlags};
use std::path::Path;
use std::sync::{Arc, Mutex};

pub struct Database {
    /// Connection pool (simplified: single connection with mutex for v1)
    conn: Arc<Mutex<Connection>>,
    /// Path to database file
    path: std::path::PathBuf,
}
```

Implement:
1. `Database::open(path: &Path, passphrase: &str) -> Result<Self, StorageError>`
   - Open SQLCipher database with PRAGMA key = 'passphrase'
   - Use OpenFlags::SQLITE_OPEN_READ_WRITE | SQLITE_OPEN_CREATE
   - Set PRAGMA cipher_compatibility = 4 for SQLCipher 4.x compatibility
   - Set PRAGMA foreign_keys = ON
   - Return StorageError::Encryption if key fails

2. `Database::connection(&self) -> Result<std::sync::MutexGuard<Connection>, StorageError>`
   - Return locked connection for use
   - Map poison error to StorageError::ConnectionPool

3. `Database::path(&self) -> &Path`
   - Return reference to database path

4. `Database::close(self) -> Result<(), StorageError>`
   - Explicitly close connection (optional, Drop handles it)

Note: Using Arc<Mutex<Connection>> instead of r2d2 pool for simplicity. rusqlite connections are not Send/Sync by default, so we need the mutex. For v1 this is sufficient; can upgrade to proper pool later if needed.

Use crate::error::StorageError for error handling.
  </action>
  <verify>cargo check --lib 2>&1 | head -30</verify>
  <done>Database struct compiles, open() connects to SQLCipher, connection() returns usable connection</done>
</task>
