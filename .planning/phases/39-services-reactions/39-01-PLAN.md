Replace the stub with a full ReactionService implementation following TypingService pattern:

1. Add ReactionError enum with variants:
   - NotLoggedIn
   - Network(NetworkError)
   - Storage(StorageError)

2. Create ReactionService struct with fields:
   - settings_repo: Arc<SettingsRepository>
   - reaction_repo: Arc<ReactionRepository>
   - reaction_aggregator: Arc<ReactionAggregator>

3. Implement constructor and current_user_id() helper (same pattern as TypingService)

4. Implement server operations (take &mut MessageClient):
   - add_reaction(client, message_id, channel_id, emoji) -> Result<Message, ReactionError>
     - Check logged in
     - Call client.add_reaction()
     - Return updated message

   - remove_reaction(client, message_id, channel_id, emoji) -> Result<Message, ReactionError>
     - Check logged in
     - Call client.remove_reaction()
     - Return updated message

   - get_reactions(client, message_id, channel_id, limit, offset, emoji_filter) -> Result<Vec<Reaction>, ReactionError>
     - Check logged in
     - Call client.get_message_reactions()
     - Convert proto reactions to domain Reaction type
     - Return reactions

5. Implement stream handling:
   - process_reaction_event(update: ReactionUpdate, user_id: String)
     - Delegates to reaction_aggregator.process(update, user_id)

6. Implement subscription methods:
   - subscribe_added() -> broadcast::Receiver<ReactionEvent>
   - subscribe_removed() -> broadcast::Receiver<ReactionEvent>

7. Implement local query methods (no auth check, no network):
   - get_reactions_local(message_id) -> Result<Vec<Reaction>, ReactionError>
     - Query reaction_repo.list_for_message()

   - get_reaction_counts_local(message_id) -> Result<Vec<ReactionCount>, ReactionError>
     - Query reaction_repo.get_reaction_counts()

   - toggle_reaction_local(message_id, emoji) -> Result<bool, ReactionError>
     - Get current user
     - Call reaction_repo.toggle()

8. Implement cache management:
   - clear() - clears aggregator cache
   - get_recent_reactions(message_id) -> Vec<ReactionEvent>
     - Delegates to aggregator

Use proto::chat_v1::ReactionUpdate for stream processing.
Use domain::reaction::{Reaction, Emoji} for local operations.
