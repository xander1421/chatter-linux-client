<task type="auto">
  <name>Task 2: Implement MimeDetector with content-based detection</name>
  <files>src/media/mime_detector.rs</files>
  <action>
Implement MimeDetector for MIME type detection:

1. Create `MimeDetector` struct (stateless) with methods:
   - `detect_from_path(path: &Path) -> Result<String, MediaError>` - Detect from file path
   - `detect_from_extension(filename: &str) -> Option<String>` - Guess from extension only
   - `detect_from_bytes(bytes: &[u8], filename: Option<&str>) -> String` - Detect from magic bytes with filename fallback

2. Detection strategy in `detect_from_path`:
   - First: Check magic bytes (file header) for reliable detection
   - Fallback: Use mime_guess from extension
   - Default: "application/octet-stream" if unknown

3. Magic byte detection for common types:
   - PNG: starts with [0x89, 0x50, 0x4E, 0x47]
   - JPEG: starts with [0xFF, 0xD8, 0xFF]
   - GIF: starts with "GIF87a" or "GIF89a"
   - WEBP: starts with "RIFF" + "WEBP" at offset 8
   - PDF: starts with "%PDF"
   - MP4/MOV: has "ftyp" at offset 4
   - MP3: starts with [0xFF, 0xFB] or "ID3"
   - WAV: starts with "RIFF" + "WAVE"
   - ZIP: starts with [0x50, 0x4B]

4. Helper method:
   - `is_image(mime: &str) -> bool`
   - `is_video(mime: &str) -> bool`
   - `is_audio(mime: &str) -> bool`
   - `is_previewable(mime: &str) -> bool` - True for images, PDF, text/code

5. Create `MediaError` enum in src/error/mod.rs:
   - Add new file `src/error/media_error.rs`
   - Variants: `FileRead(io::Error)`, `InvalidFormat(String)`, `ThumbnailGeneration(String)`, `CacheError(String)`
   - Re-export from mod.rs

Use `mime_guess::from_path()` for extension-based detection.
Read only first 16 bytes for magic byte detection (efficient).
  </action>

  <done>MimeDetector compiles with detect_from_path, magic byte detection, and MediaError type</done>
