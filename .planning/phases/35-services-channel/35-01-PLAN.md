  <action>
Create ChannelService following MessageService pattern:

1. Define ChannelError enum with variants:
   - NotLoggedIn - requires authentication
   - ChannelNotFound(ChannelId) - target channel doesn't exist
   - NotAuthorized - user lacks permission for operation
   - InvalidInput(String) - validation failure
   - Network(NetworkError) - from network ops
   - Storage(StorageError) - from storage ops

2. Create ChannelService struct with:
   - settings_repo: Arc<SettingsRepository>
   - channel_repo: Arc<ChannelRepository>

3. Implement constructor and current_user_id() helper (same pattern as MessageService)

4. Add proto-to-domain conversion helper proto_to_domain_channel() that:
   - Parses channel ID and owner ID
   - Converts proto ChannelType to domain ChannelType
   - Converts proto Config to domain ChannelConfig
   - Handles timestamp conversion (millis to DateTime<Utc>)
   - Returns domain Channel

Note: Streaming RPCs return a stream - consume first ChannelEvent and extract the channel from it.

  <action>
Implement channel creation and retrieval:

   - Signature: async fn create_channel(&self, channel_client: &mut ChannelClient, name: &str, channel_type: ChannelType, config: Option<ChannelConfig>, description: Option<&str>, image_url: Option<&str>, password: Option<&str>, initial_members: Vec<UserId>) -> Result<Channel, ChannelError>

   - Return domain Channel

   - Signature: async fn get_channel(&self, channel_client: &mut ChannelClient, channel_id: &ChannelId) -> Result<Channel, ChannelError>
   - Check logged in
   - Call channel_client.get_channel() (unary, returns proto Channel directly)
   - Convert to domain Channel
   - Upsert to local storage (insert if missing, update if exists)
   - Return domain Channel

Add use statements for tokio_stream::StreamExt.
