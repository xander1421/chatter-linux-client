  <name>Task 1: Implement Directories module</name>
  <files>src/system/directories.rs, src/error/mod.rs</files>
  <action>
Implement XDG-compliant directory management using the `directories` crate v6.

**Directories struct:**
- Use ProjectDirs::from("com", "chatter", "chatter-linux") for app-specific paths
- Store: config_dir, data_dir, cache_dir, runtime_dir (all PathBuf)
- Provide new() constructor that returns Result<Self, SystemError>
- Create directories if they don't exist (std::fs::create_dir_all)

**Methods to implement:**
- `new() -> Result<Self, SystemError>` - Initialize and create directories
- `config_dir(&self) -> &Path` - Config files (~/.config/chatter-linux)
- `data_dir(&self) -> &Path` - Persistent data (~/.local/share/chatter-linux)
- `cache_dir(&self) -> &Path` - Cache files (~/.cache/chatter-linux)
- `runtime_dir(&self) -> Option<&Path>` - Runtime files (/run/user/1000/chatter-linux, optional)
- `database_path(&self) -> PathBuf` - Convenience: data_dir/chatter.db
- `logs_dir(&self) -> PathBuf` - Convenience: data_dir/logs/

**Create SystemError in src/error/mod.rs:**
```rust
#[derive(Debug, thiserror::Error)]
pub enum SystemError {
    #[error("Failed to determine system directories")]
    DirectoryInit,
    #[error("Failed to create directory: {0}")]
    DirectoryCreate(#[source] std::io::Error),
    #[error("Keyring error: {0}")]
    Keyring(String),
}
```

Do NOT use BaseDirs or UserDirs - only ProjectDirs for app-specific paths.

<task type="auto">
  <name>Task 2: Implement Keyring module</name>
  <files>src/system/keyring.rs</files>
  <action>
Implement secure credential storage using the `keyring` crate v3.

**Keyring struct:**
- Store service name constant: "chatter-linux"
- Store username constant: "database" (identifies the credential type)

**Methods to implement:**
- `new() -> Self` - Create Keyring instance (just stores constants, no Entry yet)
- `get_passphrase(&self) -> Result<String, SystemError>` - Retrieve database passphrase
- `set_passphrase(&self, passphrase: &str) -> Result<(), SystemError>` - Store database passphrase
- `delete_passphrase(&self) -> Result<(), SystemError>` - Remove stored passphrase (for logout/reset)
- `has_passphrase(&self) -> bool` - Check if passphrase exists (get_passphrase().is_ok())

**Implementation details:**
- Use keyring::Entry::new(SERVICE, USERNAME) to create entries
- Wrap keyring errors in SystemError::Keyring with descriptive messages
- The Entry is created per-operation (not stored in struct) - this is the recommended pattern

**Error mapping:**
```rust
fn map_keyring_error(e: keyring::Error) -> SystemError {
    SystemError::Keyring(e.to_string())
}
```

Do NOT cache the passphrase in memory - always retrieve from keyring when needed.
