<task type="auto">
  <name>Task 2: Create MentionAutocomplete Slint component</name>
  <files>ui/components/mention_autocomplete.slint</files>
  <action>
Create mention suggestion popup:

**Structure:**
- Compact popup (240px wide, height based on suggestions)
- List of suggestion items (max 8 visible)
- Each item shows: avatar/icon, name, type indicator

**Properties:**
- `in property <bool> visible`
- `in property <[MentionSuggestion]> suggestions` (model with id, name, type, avatar_url)
- `in property <int> selected-index: 0` (keyboard navigation)
- `callback suggestion-selected(string, string)` (id, display_text)
- `callback close()`

**MentionSuggestion struct fields:**
- id: string
- name: string (display name)
- mention_type: string ("user", "channel", "here", "all")
- avatar_url: string (optional, for users)

**Item rendering:**
- User: Avatar + "@username"
- Channel: "#" icon + "#channel-name"
- Here/All: "@" icon + "@here" or "@all"
- Selected item (selected-index) has highlight background
- Hover also shows highlight

**Keyboard support:** (handled by parent)
- Arrow up/down changes selected-index
- Enter selects current
- Escape closes

Position hint: This popup appears above the text input, anchored to cursor position. Position is set by parent via x/y properties.
