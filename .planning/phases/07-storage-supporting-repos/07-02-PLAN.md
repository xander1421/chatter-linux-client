Create v006_reactions.rs with V006Reactions migration implementing:

```sql
CREATE TABLE reactions (
    id TEXT PRIMARY KEY,
    message_id TEXT NOT NULL REFERENCES messages(id) ON DELETE CASCADE,
    user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    -- Emoji stored as JSON (has optional custom_name, custom_url)
    emoji_json TEXT NOT NULL,
    created_at TEXT NOT NULL,
    -- Unique constraint: one reaction per user per message per emoji value
    UNIQUE(message_id, user_id, emoji_json)
);

-- Index for fetching all reactions on a message
CREATE INDEX idx_reactions_message ON reactions(message_id);

-- Index for fetching user's reactions (for "you reacted" display)
CREATE INDEX idx_reactions_user ON reactions(user_id);
```

Register V006Reactions in mod.rs default_migrations() after V005Attachments.

Implement ReactionRepository with these methods:

```rust
impl ReactionRepository {
    pub fn new(db: Arc<Database>) -> Self

    // Reaction CRUD
    pub fn insert(&self, reaction: &Reaction) -> Result<(), StorageError>
    pub fn get(&self, id: &ReactionId) -> Result<Option<Reaction>, StorageError>
    pub fn delete(&self, id: &ReactionId) -> Result<(), StorageError>

    // Query by message
    pub fn list_for_message(&self, message_id: &MessageId) -> Result<Vec<Reaction>, StorageError>

    // Query by user (for a specific message)
    pub fn list_user_reactions_on_message(
        &self,
        message_id: &MessageId,
        user_id: &UserId,
    ) -> Result<Vec<Reaction>, StorageError>

    // Toggle reaction (add if not exists, remove if exists)
    pub fn toggle(
        &self,
        message_id: &MessageId,
        user_id: &UserId,
        emoji: &Emoji,
    ) -> Result<bool, StorageError>  // Returns true if added, false if removed

    // Aggregation: get reaction counts per emoji for a message
    pub fn get_reaction_counts(&self, message_id: &MessageId) -> Result<Vec<ReactionCount>, StorageError>
}
```

For toggle operation:
1. Serialize emoji to JSON
2. Try to find existing reaction with matching (message_id, user_id, emoji_json)
3. If exists: delete and return false
4. If not exists: insert new reaction and return true

For get_reaction_counts, query:
```sql
SELECT emoji_json, COUNT(*) as count
FROM reactions
WHERE message_id = ?1
GROUP BY emoji_json
```
Then deserialize each emoji_json and construct ReactionCount (from domain::message).

AVOID: Don't use query_map with collect (lifetime issues). Use ReactionCount from the message domain, not a new type.
