Create v007_drafts.rs with V007Drafts migration implementing:

```sql
CREATE TABLE drafts (
    id TEXT PRIMARY KEY,
    -- DraftKey fields (flattened, not JSON)
    channel_id TEXT NOT NULL REFERENCES channels(id) ON DELETE CASCADE,
    thread_id TEXT,  -- NULL for main channel drafts
    -- Content
    content TEXT NOT NULL,
    reply_to TEXT,  -- MessageId being replied to
    -- Arrays stored as JSON
    attachments_json TEXT NOT NULL DEFAULT '[]',
    mentions_json TEXT NOT NULL DEFAULT '[]',
    -- Timestamps
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    -- Unique constraint: one draft per channel+thread combination
    UNIQUE(channel_id, thread_id)
);

-- Index for listing all drafts (for sync/export)
CREATE INDEX idx_drafts_updated ON drafts(updated_at DESC);
```

The UNIQUE constraint on (channel_id, thread_id) ensures only one draft exists per location. Note: SQLite treats NULL values as distinct in UNIQUE constraints, so we need to use COALESCE or a sentinel value. Use empty string '' for NULL thread_id:

Actually, change approach - use a computed column or handle in code:
```sql
-- Use a generated column for uniqueness
UNIQUE(channel_id, COALESCE(thread_id, ''))
```

SQLite doesn't support expressions in UNIQUE directly. Instead, create a unique index:
```sql
CREATE UNIQUE INDEX idx_drafts_key ON drafts(channel_id, COALESCE(thread_id, ''));
```

Register V007Drafts in mod.rs default_migrations() after V006Reactions.

```rust
    pub fn list_all(&self) -> Result<Vec<Draft>, StorageError>  // For sync/backup
    pub fn count(&self) -> Result<u64, StorageError>

    // Cleanup
    pub fn delete_empty_drafts(&self) -> Result<u64, StorageError>  // Remove drafts with empty content and no attachments
}
```

For upsert:
```sql
INSERT INTO drafts (id, channel_id, thread_id, content, reply_to, attachments_json, mentions_json, created_at, updated_at)
VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7, ?8, ?9)
ON CONFLICT(channel_id, COALESCE(thread_id, '')) DO UPDATE SET
    content = excluded.content,
    reply_to = excluded.reply_to,
    attachments_json = excluded.attachments_json,
    mentions_json = excluded.mentions_json,
    updated_at = excluded.updated_at
```

For get_by_key:
```sql
SELECT * FROM drafts WHERE channel_id = ?1 AND (thread_id = ?2 OR (thread_id IS NULL AND ?2 IS NULL))
```
Or simpler: `WHERE channel_id = ?1 AND COALESCE(thread_id, '') = COALESCE(?2, '')`

For delete_empty_drafts:
```sql
DELETE FROM drafts WHERE TRIM(content) = '' AND attachments_json = '[]'
```

AVOID: Don't create separate insert/update methods - use upsert for simplicity since drafts are identified by key.
