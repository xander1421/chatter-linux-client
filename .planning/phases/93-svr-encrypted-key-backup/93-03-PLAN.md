**Constraining decisions:**
- AES-256-GCM (not CBC) for backup encryption — authenticated encryption prevents tampering
- SVR secret (32 bytes from Argon2id) used directly as AES-256-GCM key
- Random 12-byte nonce per encryption (prepended to ciphertext)
- Backup payload format: version byte + key lengths + key data (simple binary, not protobuf — avoids proto dependency in crypto layer)
- derive_backup_id: HMAC-SHA256(svr_secret, "BackupId") — deterministic ID for server lookup
- Zeroize all sensitive intermediates

**Backup payload contains:**
1. Identity keypair (64 bytes: 32 private + 32 public)
2. Profile key (32 bytes)
3. Version byte (for future format evolution)

Total plaintext: 1 + 4 + 64 + 4 + 32 = 105 bytes (small, fits in single AES-GCM block)

  <behavior>
  **KeyBackupPayload struct:**
  - identity_keypair: [u8; 64] (32 private + 32 public)
  - profile_key: [u8; 32]

  **serialize() → Vec&lt;u8&gt;:**
  - Format: version(1) || identity_len(4 LE) || identity_keypair(64) || profile_key_len(4 LE) || profile_key(32)
  - Version byte = 0x01

  **deserialize(bytes) → Result&lt;KeyBackupPayload&gt;:**
  - Validates version byte == 0x01
  - Validates lengths match expected sizes
  - Returns CryptoError on malformed data

  **encrypt_backup(payload, svr_secret) → Vec&lt;u8&gt;:**
  - Generate random 12-byte nonce
  - AES-256-GCM encrypt serialized payload with svr_secret as key
  - Return: nonce(12) || ciphertext(N) || tag(16)

  **decrypt_backup(encrypted, svr_secret) → Result&lt;KeyBackupPayload&gt;:**
  - Split: first 12 bytes = nonce, rest = ciphertext+tag
  - AES-256-GCM decrypt
  - Deserialize plaintext to KeyBackupPayload
  - Return CryptoError::DecryptionFailed on auth tag mismatch (wrong PIN)

  **derive_backup_id(svr_secret) → [u8; 32]:**
  - HMAC-SHA256(svr_secret, "BackupId")
  - Deterministic: same PIN+username always produces same backup_id

  Test cases:
  - Round-trip: serialize → encrypt → decrypt → deserialize == original
  - Wrong key: decrypt with different svr_secret → CryptoError::DecryptionFailed
  - Tampered ciphertext: flip byte → CryptoError::DecryptionFailed
  - Malformed data: truncated bytes → CryptoError::InvalidData
  - Version mismatch: wrong version byte → CryptoError::InvalidData
  - derive_backup_id determinism: same inputs → same output
  - derive_backup_id uniqueness: different svr_secret → different output
  </behavior>
