**Constraining decisions:**
- Phase 79: SVR public key is 32 bytes (x25519), registration lock is HMAC-SHA256
- Server uses ConnectRPC (not gRPC-go), proto package `chat.v1`
- Migrations are sequential `000XXX_description.{up,down}.sql`
- Go package paths: `chatter/internal/services/{domain}/...`
- buf validate annotations for field constraints

**Key architecture:**
- Server stores OPAQUE encrypted blob — zero-knowledge, cannot read user's keys
- Rate limiting on fetch attempts (max 10 per 24h, exponential backoff on wrong PIN)
- Single active backup per user (overwrite on update, not versioned history)
- Backup identified by user_id (1:1 relationship)

Define `SvrService` with 3 RPCs:
- `StoreBackup(StoreBackupRequest) returns (StoreBackupResponse)` — upsert encrypted backup
- `FetchBackup(FetchBackupRequest) returns (FetchBackupResponse)` — retrieve with PIN proof
- `DeleteBackup(DeleteBackupRequest) returns (google.protobuf.Empty)` — remove backup

Messages:

**StoreBackupRequest:**
- `bytes encrypted_backup` — AES-256-GCM ciphertext (validate: min_len 48 — 12 nonce + 16 tag + at least 20 payload)
- `bytes backup_id_hash` — HMAC-SHA256(svr_secret, "BackupId") so server can index without knowing PIN (validate: len 32)
- `uint32 version` — monotonic version counter to prevent replay of old backups

**StoreBackupResponse:**
- `uint32 version` — confirmed version stored

**FetchBackupRequest:**
- `bytes backup_id_hash` — same HMAC-derived identifier (validate: len 32)

**FetchBackupResponse:**
- `bytes encrypted_backup` — the stored ciphertext
- `uint32 version` — backup version
- `int32 remaining_attempts` — how many fetch attempts left before lockout

**DeleteBackupRequest:**
- `bytes backup_id_hash` — identifies which backup (validate: len 32)

All requests go through the existing auth interceptor (user must be authenticated).
Do NOT add `svr_secret` or PIN to any message — the server never sees these.

Run `buf lint` to validate the proto.

**Migration up.sql:**
```sql
CREATE TABLE svr_backups (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    encrypted_backup BYTEA NOT NULL,
    backup_id_hash BYTEA NOT NULL,
    version INTEGER NOT NULL DEFAULT 1,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

-- Index for lookup by backup_id_hash (used in FetchBackup)
CREATE UNIQUE INDEX idx_svr_backups_id_hash ON svr_backups(backup_id_hash);

-- Rate limiting table for fetch attempts
CREATE TABLE svr_fetch_attempts (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    attempt_count INTEGER NOT NULL DEFAULT 0,
    last_attempt_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    locked_until TIMESTAMP WITH TIME ZONE
);
```

**Migration down.sql:**
```sql
DROP TABLE IF EXISTS svr_fetch_attempts;
DROP TABLE IF EXISTS svr_backups;
```

)
