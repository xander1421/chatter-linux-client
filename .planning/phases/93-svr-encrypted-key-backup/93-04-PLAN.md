**Public API:**

```rust
/// Create and upload an encrypted backup of the user's keys.
/// Called after registration and after PIN change.
pub async fn create_and_upload_backup(
    &self,
    svr_secret: &[u8; 32],
    identity_keypair: &[u8; 64],  // 32 private + 32 public
    profile_key: &[u8; 32],
) -> Result<(), SvrBackupError>
```

Flow:
1. Create `KeyBackupPayload` from inputs
2. `encrypt_backup(payload, svr_secret)` → ciphertext
3. `derive_backup_id(svr_secret)` → backup_id_hash
4. Get current version from settings (`crypto.svr_backup_version`), default 0, increment
5. `SvrClient::store_backup(ciphertext, backup_id_hash, new_version)`
6. Store new version in settings
7. Zeroize svr_secret copy if any

```rust
/// Fetch and decrypt backup to restore keys on a new device.
/// Returns the decrypted key material.
pub async fn fetch_and_restore_backup(
    &self,
    svr_secret: &[u8; 32],
) -> Result<KeyBackupPayload, SvrBackupError>
```

Flow:
1. `derive_backup_id(svr_secret)` → backup_id_hash
2. `SvrClient::fetch_backup(backup_id_hash)` → encrypted + version + remaining
3. `decrypt_backup(encrypted, svr_secret)` → payload
4. Store version in settings
5. Return payload (caller hydrates local stores)

```rust
/// Delete the user's backup (called on account deletion).
pub async fn delete_backup(
    &self,
    svr_secret: &[u8; 32],
) -> Result<(), SvrBackupError>
```
