**Repository** (`internal/services/svr/repository/postgres/repository.go`):

Follow the auth repository pattern. Create interface + Postgres implementation:

```go
type Repository interface {
    UpsertBackup(ctx context.Context, backup *types.SvrBackup) error
    GetBackupByIDHash(ctx context.Context, backupIDHash []byte) (*types.SvrBackup, error)
    DeleteBackup(ctx context.Context, userID string) error
    GetFetchAttempts(ctx context.Context, userID string) (*types.FetchAttemptState, error)
    IncrementFetchAttempts(ctx context.Context, userID string) error
    ResetFetchAttempts(ctx context.Context, userID string) error
}
```

`UpsertBackup`: INSERT ... ON CONFLICT (user_id) DO UPDATE — set encrypted_backup, backup_id_hash, version, updated_at. Check version > existing version (prevent replay).

`GetBackupByIDHash`: SELECT by backup_id_hash index. Return ErrBackupNotFound if no rows.

`GetFetchAttempts`: SELECT from svr_fetch_attempts. Return zero-state if no row exists.

`IncrementFetchAttempts`: UPSERT into svr_fetch_attempts, incrementing attempt_count. If attempt_count >= MaxFetchAttempts, set locked_until = NOW() + LockoutDurationMins.

`ResetFetchAttempts`: DELETE from svr_fetch_attempts (called after successful restore, or after lockout expires).

**Service** (`internal/services/svr/service/service.go`):

```go
type Service interface {
    StoreBackup(ctx context.Context, userID string, encryptedBackup []byte, backupIDHash []byte, version uint32) (uint32, error)
    FetchBackup(ctx context.Context, userID string, backupIDHash []byte) ([]byte, uint32, int32, error)
    DeleteBackup(ctx context.Context, userID string) error
}
```

`StoreBackup`: Validate inputs, create SvrBackup struct, call repo.UpsertBackup. Return confirmed version.

`FetchBackup`:
1. Check rate limit: repo.GetFetchAttempts → if locked_until > now, return ErrBackupLocked
2. If attempt window expired (last_attempt > 24h ago), repo.ResetFetchAttempts
3. repo.IncrementFetchAttempts
4. Look up backup by backup_id_hash: repo.GetBackupByIDHash
5. If found AND backup.UserID matches authenticated userID: return backup + remaining attempts
6. If not found or user mismatch: return ErrBackupNotFound (don't leak existence)
7. On success: repo.ResetFetchAttempts (successful fetch means client proved PIN knowledge)

`DeleteBackup`: repo.DeleteBackup + repo.ResetFetchAttempts.

Use `log/slog` for structured logging. Do NOT log encrypted_backup contents.
