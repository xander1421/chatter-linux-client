**PostgreSQL implementation** (`repository/postgres/repository.go`):

Follow auth repository pattern exactly. Struct has `pool *pgxpool.Pool` and `log logger.Logger`. Constructor: `New(pool *pgxpool.Pool) (*Repository, error)` with `logger.WithComponent("svr_postgres_repository")`.

Implement each method:

**StoreBackup** — Use `INSERT ... ON CONFLICT (user_id) DO UPDATE` (upsert). Only update if new version is greater (prevent replay):

```sql
INSERT INTO svr_backups (user_id, encrypted_backup, backup_id_hash, version, created_at, updated_at)
VALUES ($1, $2, $3, $4, NOW(), NOW())
ON CONFLICT (user_id) DO UPDATE
SET encrypted_backup = EXCLUDED.encrypted_backup,
    backup_id_hash = EXCLUDED.backup_id_hash,
    version = EXCLUDED.version,
    updated_at = NOW()
WHERE svr_backups.version < EXCLUDED.version
```
Check `result.RowsAffected()` — if 0, return `types.ErrVersionConflict`.

**FetchBackup** — `SELECT user_id, encrypted_backup, backup_id_hash, version, created_at, updated_at FROM svr_backups WHERE backup_id_hash = $1`. Return `types.ErrBackupNotFound` on `pgx.ErrNoRows`.

**DeleteBackup** — `DELETE FROM svr_backups WHERE backup_id_hash = $1`. No error if not found (idempotent).

**GetFetchAttemptState** — `SELECT user_id, attempt_count, last_attempt_at, locked_until FROM svr_fetch_attempts WHERE user_id = $1`. Return nil (not error) if no rows — means no attempts yet.

**IncrementFetchAttempts** — Use upsert with automatic lockout when threshold reached:
```sql
INSERT INTO svr_fetch_attempts (user_id, attempt_count, last_attempt_at, locked_until)
VALUES ($1, 1, NOW(), NULL)
ON CONFLICT (user_id) DO UPDATE
SET attempt_count = svr_fetch_attempts.attempt_count + 1,
    last_attempt_at = NOW(),
    locked_until = CASE
        WHEN svr_fetch_attempts.attempt_count + 1 >= 10 THEN NOW() + INTERVAL '60 minutes'
        ELSE svr_fetch_attempts.locked_until
    END
RETURNING user_id, attempt_count, last_attempt_at, locked_until
```
Use the constants from types (MaxFetchAttempts=10, LockoutDurationMins=60) — embed them as literals in the SQL or use fmt.Sprintf to build the interval. Scan and return the updated state.

**ResetFetchAttempts** — `DELETE FROM svr_fetch_attempts WHERE user_id = $1`. Idempotent.

Use `pgx` imports: `github.com/jackc/pgx/v5`, `github.com/jackc/pgx/v5/pgxpool`. Use `errors.Is(err, pgx.ErrNoRows)` for not-found checks. Log errors with `r.log.WithError(err).Error("message")`.

Create the service in a single file. Define:

**Service interface:**
```go
type Service interface {
    StoreBackup(ctx context.Context, userID string, req *chatsvr.StoreBackupRequest) (int32, error)
    FetchBackup(ctx context.Context, userID string, backupIDHash []byte) (*types.SvrBackup, int32, error)
    DeleteBackup(ctx context.Context, userID string, backupIDHash []byte) error
}
```

FetchBackup returns `(backup, remainingAttempts, error)`.

**Config struct** (simplified — SVR doesn't need Temporal, Vault, Redis, or goroutine pools):
```go
type Config struct {
    Repository types.Repository
    Logger     logger.Logger
}
```

**serviceImpl struct:**
```go
type serviceImpl struct {
    repo types.Repository
    log  logger.Logger
}
```

**Constructor:**
```go
func New(config Config) Service {
    log := config.Logger
    if log == nil {
        log = logger.WithComponent("svr_service")
    }
    return &serviceImpl{repo: config.Repository, log: log}
}
```

**StoreBackup implementation:**
1. Create `types.SvrBackup` from request fields (UserID from param, EncryptedBackup/BackupIdHash/Version from proto request).
2. Call `s.repo.StoreBackup(ctx, backup)`.
3. On success, reset fetch attempts: `s.repo.ResetFetchAttempts(ctx, userID)` — a successful store proves the user knows their PIN.
4. Return `int32(req.Version), nil`.
5. On ErrVersionConflict, return that error as-is.

**FetchBackup implementation (rate-limited):**
1. Get current attempt state: `s.repo.GetFetchAttemptState(ctx, userID)`.
2. If state != nil and `state.LockedUntil != nil && state.LockedUntil.After(time.Now())`: return `nil, 0, types.ErrBackupLocked`.
3. If state != nil and `time.Since(state.LastAttempt) > types.AttemptWindowHours * time.Hour`: window expired, reset attempts: `s.repo.ResetFetchAttempts(ctx, userID)`.
4. Increment attempts: `state, err := s.repo.IncrementFetchAttempts(ctx, userID)`.
5. Compute `remaining := int32(types.MaxFetchAttempts) - state.AttemptCount`. Clamp to 0 minimum.
6. If state.LockedUntil is now set (DB did it because count >= 10): return `nil, 0, types.ErrBackupLocked`.
7. Fetch backup: `backup, err := s.repo.FetchBackup(ctx, backupIDHash)`.
8. On ErrBackupNotFound: return error with remaining attempts (don't leak info about whether backup exists vs wrong hash — but since the user is authenticated and we're returning remaining attempts anyway, it's fine to return NotFound).
9. On success: return `backup, remaining, nil`. Do NOT reset attempts on fetch success — only StoreBackup (which proves PIN knowledge for upload) and DeleteBackup reset. FetchBackup merely returns the encrypted blob; the client still needs to decrypt it locally to prove they know the PIN.

**DeleteBackup implementation:**
1. Call `s.repo.DeleteBackup(ctx, backupIDHash)`.
2. Reset fetch attempts: `s.repo.ResetFetchAttempts(ctx, userID)`.
3. Return error if any.

Imports: `chatter/internal/services/svr/types`, `chatter/internal/utils/logger`, `chatter/pkg/proto/chat/v1/svr` (aliased as `chatsvr`), `context`, `time`.

func Register(mux *http.ServeMux, c *container.Container, opts ...connect.HandlerOption) error {
    svc, err := svr.GetService(c)
