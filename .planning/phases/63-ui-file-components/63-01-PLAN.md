Create new file src/ui/file_data.rs with:
1. AttachmentItemData struct with fields:
   - attachment_id: String
   - file_name: String
   - file_size: String (formatted, e.g., "2.5 MB")
   - mime_type: String
   - category: String ("image", "video", "audio", "document", "code", "archive", "other")
   - thumbnail_url: String (empty if no preview)
   - is_ready: bool
   - is_uploading: bool
   - upload_progress: f32 (0.0-1.0)
   - is_downloading: bool
   - download_progress: f32 (0.0-1.0)

2. Builder methods: new(id), with_file_name(), with_file_size(), with_mime_type(), with_category(), with_thumbnail(), with_ready(), with_uploading(), with_downloading()

3. From<&Attachment> conversion that maps:
   - metadata.name -> file_name
   - metadata.formatted_size() -> file_size
   - metadata.mime_type -> mime_type
   - category().to_string() -> category (lowercase)
   - status == Ready -> is_ready
   - status == Uploading -> is_uploading
   - (thumbnail_url must be set externally)

4. Helper function category_icon(category: &str) -> &'static str that returns:
   - "image" -> "🖼️"
   - "video" -> "🎬"
   - "audio" -> "🎵"
   - "document" -> "📄"
   - "code" -> "📝"
   - "archive" -> "📦"
   - _ -> "📎"

Update src/ui/mod.rs to add `pub mod file_data;` and re-export AttachmentItemData and category_icon.
