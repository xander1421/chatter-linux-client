  <name>Task 1: Create FilePreviewData and CodeLineData structs</name>
  <files>src/ui/file_data.rs, src/ui/mod.rs</files>
  <action>
Add to src/ui/file_data.rs:

1. CodeLineData struct for a single line of highlighted code:
   - line_number: i32
   - content: String (plain text for the line)
   - html_content: String (optional - for rich rendering if supported)

   Note: Slint doesn't support rich text inline styling, so we'll display plain text with monospace font. The html_content field is for future use if we add a web view.

2. FilePreviewData struct for preview panel state:
   - file_name: String
   - file_path: String
   - preview_type: String ("code", "pdf", "image", "video", "audio", "none")
   - language: String (for code: "rust", "python", etc.)
   - line_count: i32 (for code: total lines)
   - page_count: i32 (for PDF: total pages)
   - current_page: i32 (for PDF: current page, 1-indexed)
   - error_message: String (if preview failed)

3. Builder methods for FilePreviewData:
   - new(file_name, file_path)
   - with_code(language, line_count)
   - with_pdf(page_count)
   - with_image()
   - with_error(message)
   - with_current_page(page)

4. Helper function to flatten code preview:
   ```rust
   pub fn flatten_code_lines(lines: &[HighlightedLine]) -> Vec<CodeLineData> {
       lines.iter().map(|line| {
           let content = line.segments.iter()
               .map(|seg| seg.text.as_str())
               .collect::<String>();
           CodeLineData {
               line_number: line.line_number as i32,
               content,
               html_content: String::new(),
           }
       }).collect()
   }
   ```

Update src/ui/mod.rs to re-export CodeLineData, FilePreviewData, and flatten_code_lines.
