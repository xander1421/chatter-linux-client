<task type="auto">
  <name>Task 1: Implement AudioPlayer with rodio playback</name>
  <files>src/media/audio_player.rs, src/error/media_error.rs</files>
  <action>
Implement AudioPlayer struct using rodio crate:

1. AudioPlayer struct with:
   - OutputStream and OutputStreamHandle from rodio (stored in struct for lifetime)
   - Sink for playback control
   - Current file path (Option<PathBuf>)
   - Playback state tracking (PlaybackState enum: Stopped, Playing, Paused)

2. PlaybackState enum:
   - Stopped
   - Playing { position: Duration, duration: Duration }
   - Paused { position: Duration, duration: Duration }

3. AudioPlayer methods:
   - new() -> Result<Self, MediaError> - Creates OutputStream and Sink
   - load(&mut self, path: &Path) -> Result<Duration, MediaError> - Loads audio file, returns duration
   - play(&mut self) -> Result<(), MediaError> - Starts/resumes playback
   - pause(&mut self) - Pauses playback
   - stop(&mut self) - Stops and resets to beginning
   - seek(&mut self, position: Duration) -> Result<(), MediaError> - Seek to position
   - set_volume(&mut self, volume: f32) - Set volume (0.0-1.0)
   - state(&self) -> PlaybackState - Get current state
   - is_playing(&self) -> bool
   - is_paused(&self) -> bool

4. Add PlaybackError variant to MediaError:
   - PlaybackError(String) for rodio errors

5. Support formats: MP3, WAV, OGG, FLAC (rodio defaults)

Use rodio's Decoder::new() for format detection. Handle errors gracefully with MediaError.

Note: rodio's Sink::try_seek requires rodio feature flag, check if available. If not, recreate sink at position (common workaround).
  </action>

  <done>AudioPlayer struct with load, play, pause, stop, seek, volume control methods compiles cleanly</done>

<task type="auto">
  <name>Task 2: Implement VideoPlayer with external player delegation</name>
  <files>src/media/video_player.rs</files>
  <action>
Implement VideoPlayer that delegates to system video player:

1. VideoPlayer struct (stateless, matches pattern from Phase 52):
   - No internal state, just a namespace for methods

2. VideoPlayer methods:
   - play(path: &Path) -> Result<(), MediaError> - Opens video in system player using open::that()
   - play_with_app(path: &Path, app: &str) -> Result<(), MediaError> - Opens with specific app (mpv, vlc, etc.)
   - is_supported_format(mime_type: &str) -> bool - Check if MIME is video/*
   - get_thumbnail(path: &Path, cache: &ThumbnailCache) -> Option<PathBuf> - Get cached thumbnail if exists

3. Supported MIME types for is_supported_format:
   - video/mp4
   - video/webm
   - video/x-matroska (mkv)
   - video/quicktime (mov)
   - video/x-msvideo (avi)

Rationale for external delegation: Slint doesn't have built-in video playback, and embedding GStreamer/ffmpeg adds significant complexity. For v1, delegate to system player (matches "ship first" philosophy from PROJECT.md). In-app video can be added in a future phase if needed.

Use open::that_in_background() to not block the UI thread.
  </action>
