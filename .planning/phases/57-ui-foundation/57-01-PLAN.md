Implement UiBridge to connect Rust state stores to Slint UI.

The bridge should:
1. Hold references to state stores (UIState, AuthState) and EventBus
2. Provide methods to:
   - `new(ui_state, auth_state, event_bus)` - constructor
   - `setup_callbacks(window: &MainWindow)` - wire Slint callbacks to Rust handlers
   - `start_state_sync(window: Weak<MainWindow>)` - spawn async task to push state changes to Slint
3. Use `Weak<MainWindow>` for the async task to avoid preventing window close

Pattern for state sync:
```rust
pub async fn start_state_sync(&self, window: slint::Weak<MainWindow>) {
    let mut rx = self.ui_state.subscribe();
    while let Ok(state) = rx.recv().await {
        if let Some(window) = window.upgrade() {
            // Update Slint properties from state
            window.invoke_from_rust(|| {
                // Set properties
            });
        } else {
            break; // Window closed
        }
    }
}
```

For now, the bridge just holds the state stores and event bus. Actual property binding will expand in later phases as we add Slint properties.

Add `SlintBridge` type alias and re-export from mod.rs.

<task type="auto">
  <name>Task 3: Wire UiBridge into main.rs application startup</name>
  <files>src/main.rs</files>
  <action>
Update main.rs to:
1. Initialize state stores (UIState, AuthState)
2. Create EventBus
3. Create UiBridge with the state stores and event bus
4. Create MainWindow
5. Call setup_callbacks on the bridge
6. Spawn state sync task using tokio
7. Run the Slint event loop

The pattern:
```rust
#[tokio::main]
async fn main() {
    // Initialize tracing
    tracing_subscriber::init();

    // Create state stores
    let ui_state = UIState::new();
    let auth_state = AuthState::new();
    let event_bus = EventBus::new();

    // Create bridge
    let bridge = UiBridge::new(ui_state, auth_state, event_bus);

    // Create window
    let window = MainWindow::new().expect("Failed to create window");

    // Setup callbacks
    bridge.setup_callbacks(&window);

    // Spawn state sync (runs in background)
    let weak_window = window.as_weak();
    tokio::spawn(async move {
        bridge.start_state_sync(weak_window).await;
    });

    // Run Slint event loop (blocks until window closes)
    window.run().expect("Failed to run application");
}
```

Note: slint::run_event_loop() may be needed depending on Slint version. Check which pattern works.
