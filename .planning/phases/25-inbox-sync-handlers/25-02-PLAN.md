  <files>src/inbox/handlers/mod.rs</files>
  <action>
Add the three new DomainEvent variants needed by Phase 25 handlers:

1. Add `KeyExchangeReceived` variant:
   ```rust
   /// Mailbox key exchange received (for ephemeral DM mailboxes).
   KeyExchangeReceived {
       /// User who sent the key exchange.
       sender_id: UserId,
       /// Conversation this key is for.
       conversation_id: ChannelId,
       /// Ephemeral Ed25519 public key (32 bytes).
       ephemeral_public_key: [u8; 32],
       /// When the key exchange was initiated (ms since epoch).
       timestamp: u64,
   },
   ```

2. Add `SenderKeyReceived` variant:
   ```rust
   /// Group sender key distribution received.
   SenderKeyReceived {
       /// User who sent the sender key.
       sender_id: UserId,
       /// Channel/group this key is for.
       channel_id: ChannelId,
       /// Serialized SKDM (libsignal format) for crypto layer.
       distribution_message: Vec<u8>,
       /// When sent (ms since epoch).
       timestamp: u64,
   },
   ```

3. Add `DeleteForMeSync` variant:
   ```rust
   /// Multi-device sync: message deleted locally on another device.
   DeleteForMeSync {
       /// Conversation containing the deleted message.
       conversation_id: ChannelId,
       /// Author of the deleted message.
       target_author_id: UserId,
       /// The deleted message (derived from timestamp).
       target_message_id: MessageId,
       /// When the sync was issued (ms since epoch).
       timestamp: u64,
   },
   ```

4. Update `channel_id()` method to handle new variants:
   - KeyExchangeReceived returns Some(conversation_id)
   - SenderKeyReceived returns Some(channel_id)
   - DeleteForMeSync returns Some(conversation_id)

5. Update `is_transient()` - new events are NOT transient (should be processed).

Add tests for the new event variants in the existing test module.
  </action>
