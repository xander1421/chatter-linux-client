# Phase 20-04: Specialized Stream Handlers (Typing, Reaction, ReadReceipt)

## Objective

Implement the remaining specialized stream handlers that provide higher-level APIs on top of the `MessageEventRouter`. These provide debouncing, aggregation, and convenience methods for specific event types.

## Execution Context

- **Depends on**: Phase 20-02 (MessageEventRouter)
- **Pattern**: Thin wrappers with domain-specific logic
- **Key files**:
  - `src/network/streaming/typing_stream.rs`
  - `src/network/streaming/reaction_stream.rs`
  - `src/network/streaming/read_receipt_stream.rs`
  - `src/network/streaming/mod.rs` (exports)

## Context

While `MessageEventRouter` provides raw typed channels, consumers often need:
- **Typing**: Debounced aggregation of who's typing in each channel
- **Reactions**: Grouped by message for UI updates
- **Read Receipts**: Aggregated per-user high-water marks

These modules subscribe to `MessageEventRouter` and provide higher-level APIs.

//! Typing indicator stream handler.
//!
//! Tracks who is currently typing in each channel with automatic expiry.

use std::collections::{HashMap, HashSet};
use std::sync::Arc;
use std::time::{Duration, Instant};

use parking_lot::RwLock;
use tokio::sync::broadcast;

use crate::proto::chat_v1::TypingIndicator;

/// Default typing indicator timeout.
const TYPING_TIMEOUT: Duration = Duration::from_secs(10);

/// Capacity for typing event channel.
const CHANNEL_CAPACITY: usize = 64;

/// Typing stream handler with per-channel aggregation.
///
/// Tracks which users are typing in each channel, with automatic
/// expiry after timeout. Provides efficient queries for UI.
///
/// # Example
///
/// ```ignore
/// let typing = TypingAggregator::new();
///
/// // Track typing from stream events
/// typing.on_typing_started("channel-1", "user-123");
///
/// // Query who's typing
/// let typers = typing.get_typing_users("channel-1");
/// // Returns ["user-123"] if within timeout
///
/// // Clean up expired entries
/// typing.cleanup_expired();
/// ```
pub struct TypingAggregator {
    /// Per-channel typing state (channel_id -> user_id -> expiry time).
    state: Arc<RwLock<HashMap<String, HashMap<String, Instant>>>>,

    /// Broadcast for typing state changes.
    changes: broadcast::Sender<TypingStateChange>,

    /// Typing timeout duration.
    timeout: Duration,
}

/// Typing state change event.
#[derive(Clone, Debug)]
pub struct TypingStateChange {
    /// Channel where typing state changed.
    pub channel_id: String,
    /// Users currently typing (after the change).
    pub typing_users: Vec<String>,
}

impl TypingAggregator {
    /// Create a new TypingAggregator with default timeout.
    pub fn new() -> Self {
        Self::with_timeout(TYPING_TIMEOUT)
    }

    /// Create a new TypingAggregator with custom timeout.
    pub fn with_timeout(timeout: Duration) -> Self {
        Self {
            state: Arc::new(RwLock::new(HashMap::new())),
            changes: broadcast::channel(CHANNEL_CAPACITY).0,
            timeout,
        }
    }

    /// Subscribe to typing state changes.
    pub fn on_typing_change(&self) -> broadcast::Receiver<TypingStateChange> {
        self.changes.subscribe()
    }

    /// Process a typing indicator event.
    pub fn process(&self, indicator: TypingIndicator, channel_id: &str) {
        if indicator.is_typing {
            self.on_typing_started(channel_id, &indicator.user_id);
        } else {
            self.on_typing_stopped(channel_id, &indicator.user_id);
        }
    }

    /// Mark a user as typing in a channel.
    pub fn on_typing_started(&self, channel_id: &str, user_id: &str) {
        let expiry = Instant::now() + self.timeout;

        let changed = {
            let mut state = self.state.write();
            let channel = state.entry(channel_id.to_string()).or_default();
            let was_empty = channel.is_empty();
            channel.insert(user_id.to_string(), expiry);
            was_empty || !channel.contains_key(user_id)
        };

        if changed {
            self.emit_change(channel_id);
        }
    }

    /// Mark a user as no longer typing in a channel.
    pub fn on_typing_stopped(&self, channel_id: &str, user_id: &str) {
        let changed = {
            let mut state = self.state.write();
            if let Some(channel) = state.get_mut(channel_id) {
                channel.remove(user_id).is_some()
            } else {
                false
            }
        };

        if changed {
            self.emit_change(channel_id);
        }
    }

    /// Get list of users currently typing in a channel.
    ///
    /// Automatically filters out expired entries.
    pub fn get_typing_users(&self, channel_id: &str) -> Vec<String> {
        let now = Instant::now();
        let state = self.state.read();

        state
            .get(channel_id)
            .map(|channel| {
                channel
                    .iter()
                    .filter(|(_, expiry)| **expiry > now)
                    .map(|(user_id, _)| user_id.clone())
                    .collect()
            })
            .unwrap_or_default()
    }

    /// Check if anyone is typing in a channel.
    pub fn is_anyone_typing(&self, channel_id: &str) -> bool {
        !self.get_typing_users(channel_id).is_empty()
    }

    /// Clean up expired typing entries.
    ///
    /// Call periodically (e.g., every 5 seconds) to remove stale entries.
    pub fn cleanup_expired(&self) -> usize {
        let now = Instant::now();
        let mut removed = 0;
        let mut channels_changed = Vec::new();

        {
            let mut state = self.state.write();

            for (channel_id, channel) in state.iter_mut() {
                let before = channel.len();
                channel.retain(|_, expiry| *expiry > now);
                let after = channel.len();

                if before != after {
                    removed += before - after;
                    channels_changed.push(channel_id.clone());
                }
            }

            // Remove empty channels
            state.retain(|_, channel| !channel.is_empty());
        }

        // Emit changes for affected channels
        for channel_id in channels_changed {
            self.emit_change(&channel_id);
        }

        removed
    }

    /// Clear all typing state.
    pub fn clear(&self) {
        self.state.write().clear();
    }

    /// Emit a typing state change event.
    fn emit_change(&self, channel_id: &str) {
        let typing_users = self.get_typing_users(channel_id);
        let _ = self.changes.send(TypingStateChange {
            channel_id: channel_id.to_string(),
            typing_users,
        });
    }
}

impl Default for TypingAggregator {
    fn default() -> Self {
        Self::new()
    }
}

//! Reaction stream handler.
//!
//! Provides reaction events grouped by message for efficient UI updates.

use std::collections::HashMap;
use std::sync::Arc;

use parking_lot::RwLock;
use tokio::sync::broadcast;

use crate::proto::chat_v1::ReactionUpdate;

/// Capacity for reaction event channel.
const CHANNEL_CAPACITY: usize = 128;

/// Maximum messages to track reactions for.
const CACHE_CAPACITY: usize = 500;

/// Reaction stream handler with per-message aggregation.
///
/// Tracks recent reaction changes and provides efficient
/// queries for UI components.
pub struct ReactionAggregator {
    /// Recent reaction events (message_id -> reactions).
    recent: Arc<RwLock<ReactionCache>>,

    /// Broadcast for reaction events.
    added: broadcast::Sender<ReactionUpdate>,
    removed: broadcast::Sender<ReactionUpdate>,
}

/// Simple LRU cache for recent reactions.
struct ReactionCache {
    /// Map of message_id -> list of recent reaction updates.
    entries: HashMap<String, Vec<ReactionUpdate>>,
    /// Order of message IDs for LRU eviction.
    order: Vec<String>,
    capacity: usize,
}

impl ReactionCache {
    fn new(capacity: usize) -> Self {
        Self {
            entries: HashMap::new(),
            order: Vec::new(),
            capacity,
        }
    }

    fn add(&mut self, message_id: String, reaction: ReactionUpdate) {
        // Remove from order if exists (to re-add at end)
        self.order.retain(|id| id != &message_id);

        // Add to entries
        self.entries
            .entry(message_id.clone())
            .or_default()
            .push(reaction);

        // Add to order
        self.order.push(message_id);

        // Evict if over capacity
        while self.order.len() > self.capacity {
            if let Some(old_id) = self.order.first().cloned() {
                self.order.remove(0);
                self.entries.remove(&old_id);
            }
        }
    }

    fn get(&self, message_id: &str) -> Option<&Vec<ReactionUpdate>> {
        self.entries.get(message_id)
    }

    fn len(&self) -> usize {
        self.entries.len()
    }

    fn clear(&mut self) {
        self.entries.clear();
        self.order.clear();
    }
}

impl ReactionAggregator {
    /// Create a new ReactionAggregator.
    pub fn new() -> Self {
        Self {
            recent: Arc::new(RwLock::new(ReactionCache::new(CACHE_CAPACITY))),
            added: broadcast::channel(CHANNEL_CAPACITY).0,
            removed: broadcast::channel(CHANNEL_CAPACITY).0,
        }
    }

    /// Subscribe to reaction added events.
    pub fn on_reaction_added(&self) -> broadcast::Receiver<ReactionUpdate> {
        self.added.subscribe()
    }

    /// Subscribe to reaction removed events.
    pub fn on_reaction_removed(&self) -> broadcast::Receiver<ReactionUpdate> {
        self.removed.subscribe()
    }

    /// Process a reaction added event.
    pub fn process_added(&self, reaction: ReactionUpdate) {
        self.recent
            .write()
            .add(reaction.message_id.clone(), reaction.clone());
        let _ = self.added.send(reaction);
    }

    /// Process a reaction removed event.
    pub fn process_removed(&self, reaction: ReactionUpdate) {
        let _ = self.removed.send(reaction);
    }

    /// Get recent reactions for a message.
    pub fn get_recent_reactions(&self, message_id: &str) -> Vec<ReactionUpdate> {
        self.recent
            .read()
            .get(message_id)
            .cloned()
            .unwrap_or_default()
    }

    /// Get the number of messages with cached reactions.
    pub fn cache_size(&self) -> usize {
        self.recent.read().len()
    }

    /// Clear the reaction cache.
    pub fn clear(&self) {
        self.recent.write().clear();
    }
}

impl Default for ReactionAggregator {
    fn default() -> Self {
        Self::new()
    }
}

//! Read receipt stream handler.
//!
//! Tracks read receipt high-water marks per user per channel.

use std::collections::HashMap;
use std::sync::Arc;

use parking_lot::RwLock;
use tokio::sync::broadcast;

use crate::proto::chat_v1::ReadReceipt;

/// Capacity for read receipt event channel.
const CHANNEL_CAPACITY: usize = 64;

/// Read receipt aggregator with high-water mark tracking.
///
/// Tracks the last read message for each user in each channel.
/// Only the highest (most recent) read position is kept.
pub struct ReadReceiptAggregator {
    /// Per-channel read states (channel_id -> user_id -> last read message).
    state: Arc<RwLock<HashMap<String, HashMap<String, ReadState>>>>,

    /// Broadcast for read receipt events.
    events: broadcast::Sender<ReadReceipt>,
}

/// Read state for a user in a channel.
#[derive(Clone, Debug)]
pub struct ReadState {
    /// Last read message ID.
    pub message_id: String,
    /// Timestamp of the read receipt.
    pub timestamp: u64,
}

impl ReadReceiptAggregator {
    /// Create a new ReadReceiptAggregator.
    pub fn new() -> Self {
        Self {
            state: Arc::new(RwLock::new(HashMap::new())),
            events: broadcast::channel(CHANNEL_CAPACITY).0,
        }
    }

    /// Subscribe to read receipt events.
    pub fn on_read_receipt(&self) -> broadcast::Receiver<ReadReceipt> {
        self.events.subscribe()
    }

    /// Process a read receipt event.
    pub fn process(&self, receipt: ReadReceipt) {
        // Update state (only if newer)
        {
            let mut state = self.state.write();
            let channel = state.entry(receipt.channel_id.clone()).or_default();

            let should_update = channel
                .get(&receipt.user_id)
                .map(|existing| receipt.timestamp > existing.timestamp)
                .unwrap_or(true);

            if should_update {
                channel.insert(
                    receipt.user_id.clone(),
                    ReadState {
                        message_id: receipt.last_read_message_id.clone(),
                        timestamp: receipt.timestamp,
                    },
                );
            }
        }

        // Broadcast the event
        let _ = self.events.send(receipt);
    }

    /// Get the last read message ID for a user in a channel.
    pub fn get_last_read(&self, channel_id: &str, user_id: &str) -> Option<String> {
        self.state
            .read()
            .get(channel_id)
            .and_then(|channel| channel.get(user_id))
            .map(|state| state.message_id.clone())
    }

    /// Get all read states for a channel.
    pub fn get_channel_read_states(&self, channel_id: &str) -> HashMap<String, ReadState> {
        self.state
            .read()
            .get(channel_id)
            .cloned()
            .unwrap_or_default()
    }

    /// Check if a specific message has been read by a user.
    ///
    /// Note: This only checks the high-water mark, not individual messages.
    /// A message is considered "read" if the user's last read is at or after it.
    pub fn has_user_read_message(
        &self,
        channel_id: &str,
        user_id: &str,
        message_id: &str,
    ) -> Option<bool> {
        // We can't easily compare message IDs without ordering info.
        // This returns Some(true) if the exact message is the last read.
        // For proper comparison, callers should use message timestamps.
        self.get_last_read(channel_id, user_id)
            .map(|last| last == message_id)
    }

    /// Get users who have read up to a specific message.
    ///
    /// Returns users whose last_read_message_id matches the given message.
    pub fn get_readers_of_message(&self, channel_id: &str, message_id: &str) -> Vec<String> {
        self.state
            .read()
            .get(channel_id)
            .map(|channel| {
                channel
                    .iter()
                    .filter(|(_, state)| state.message_id == message_id)
                    .map(|(user_id, _)| user_id.clone())
                    .collect()
            })
            .unwrap_or_default()
    }

    /// Clear all read states.
    pub fn clear(&self) {
        self.state.write().clear();
    }

    /// Clear read states for a specific channel.
    pub fn clear_channel(&self, channel_id: &str) {
        self.state.write().remove(channel_id);
    }
}

impl Default for ReadReceiptAggregator {
    fn default() -> Self {
        Self::new()
    }
}
