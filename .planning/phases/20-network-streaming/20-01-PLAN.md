# Phase 20-01: StreamManager and Core Infrastructure

## Objective

Implement the `StreamManager` that orchestrates all real-time gRPC streams, along with the core streaming infrastructure (stream traits, event routing, lifecycle management).

## Execution Context

- **Depends on**: Phase 18 (Message/Channel clients with streaming RPCs), Phase 16 (gRPC Foundation)
- **Pattern**: Follow existing client patterns from `message_client.rs`, `user_client.rs`
- **Key files**:
  - `src/network/streaming/stream_manager.rs`
  - `src/network/connection.rs` (existing - connection state machine)
  - `src/network/grpc/client_pool.rs` (existing - channel management)

## Context

The network layer has stub files in `src/network/streaming/` with 6 stream handlers. The gRPC clients already expose streaming methods:
- `MessageClient::stream_global_events()` - streams `MessageEvent` (includes message, reaction, typing, read receipt events)
- `UserClient::stream_presence()` - streams `PresenceUpdate`
- `UserClient::stream_user_events()` - streams `UserEvent` (profile, friend, presence changes)

The `MessageEvent` proto type already consolidates multiple event types:
```protobuf
message MessageEvent {
  oneof event {
    Message message_sent = 4;
    Message message_updated = 5;
    string message_deleted_id = 6;
    ReactionUpdate reaction_added = 7;
    ReactionUpdate reaction_removed = 8;
    ReadReceipt read_receipt = 9;
    TypingIndicator typing_indicator = 10;
  }
}
```

This means `MessageStream`, `TypingStream`, `ReactionStream`, and `ReadReceiptStream` can all be derived from the single `StreamGlobalEvents` RPC, while `PresenceStream` uses the separate `StreamPresence` RPC.

```rust
use std::sync::Arc;
use tokio::sync::{broadcast, oneshot};
use tokio::task::JoinHandle;

use crate::error::NetworkError;
use crate::network::connection::ConnectionStateMachine;

/// Handle for controlling a running stream.
pub struct StreamHandle {
    /// Task handle for the stream processor.
    task: JoinHandle<()>,
    /// Signal to stop the stream gracefully.
    shutdown_tx: oneshot::Sender<()>,
}

impl StreamHandle {
    /// Create a new stream handle.
    pub fn new(task: JoinHandle<()>, shutdown_tx: oneshot::Sender<()>) -> Self {
        Self { task, shutdown_tx }
    }

    /// Stop the stream gracefully.
    pub fn stop(self) {
        let _ = self.shutdown_tx.send(());
    }

    /// Check if the stream task is still running.
    pub fn is_running(&self) -> bool {
        !self.task.is_finished()
    }

    /// Wait for the stream task to complete.
    pub async fn join(self) -> Result<(), tokio::task::JoinError> {
        self.task.await
    }
}

/// Configuration for stream behavior.
#[derive(Clone, Debug)]
pub struct StreamConfig {
    /// Capacity for internal event buffers.
    pub buffer_capacity: usize,
    /// Whether to auto-reconnect on stream errors.
    pub auto_reconnect: bool,
}

impl Default for StreamConfig {
    fn default() -> Self {
        Self {
            buffer_capacity: 256,
            auto_reconnect: true,
        }
    }
}
```

use parking_lot::Mutex;
use crate::network::grpc::client_pool::GrpcClientPool;

/// Manager for all real-time gRPC streams.
///
/// Orchestrates message events, presence updates, and user events streams.
/// Integrates with ConnectionStateMachine to react to connection changes.
///
/// # Example
///
/// ```ignore
/// let pool = GrpcClientPool::new("http://localhost:50051")?;
/// pool.connect().await?;
///
/// let conn = ConnectionStateMachine::new();
/// let manager = StreamManager::new(pool.clone(), conn.clone(), StreamConfig::default());
///
/// manager.start_all().await?;
/// // ... use streams ...
/// manager.stop_all().await;
/// ```
pub struct StreamManager {
    pool: Arc<GrpcClientPool>,
    connection: ConnectionStateMachine,
    config: StreamConfig,

    /// Active stream handles.
    handles: Mutex<StreamHandles>,

    /// Broadcast channel for shutting down all streams.
    shutdown: broadcast::Sender<()>,
}

/// Container for active stream handles.
struct StreamHandles {
    message_events: Option<StreamHandle>,
    presence: Option<StreamHandle>,
    user_events: Option<StreamHandle>,
}

impl Default for StreamHandles {
    fn default() -> Self {
        Self {
            message_events: None,
            presence: None,
            user_events: None,
        }
    }
}

### Task 3: Implement StreamManager constructor and basic methods
File: `src/network/streaming/stream_manager.rs`

```rust
impl StreamManager {
    /// Shutdown broadcast capacity.
    const SHUTDOWN_CAPACITY: usize = 4;

    /// Create a new StreamManager.
    ///
    /// # Arguments
    ///
    /// * `pool` - gRPC client pool for creating service clients
    /// * `connection` - Connection state machine for state tracking
    /// * `config` - Stream configuration
    pub fn new(
        pool: Arc<GrpcClientPool>,
        connection: ConnectionStateMachine,
        config: StreamConfig,
    ) -> Self {
        let (shutdown, _) = broadcast::channel(Self::SHUTDOWN_CAPACITY);
        Self {
            pool,
            connection,
            config,
            handles: Mutex::new(StreamHandles::default()),
            shutdown,
        }
    }

    /// Check if currently streaming.
    pub fn is_streaming(&self) -> bool {
        let handles = self.handles.lock();
        handles.message_events.as_ref().map_or(false, |h| h.is_running())
            || handles.presence.as_ref().map_or(false, |h| h.is_running())
            || handles.user_events.as_ref().map_or(false, |h| h.is_running())
    }

    /// Get a shutdown receiver for stream tasks.
    fn shutdown_receiver(&self) -> broadcast::Receiver<()> {
        self.shutdown.subscribe()
    }
}
```

### Task 4: Implement start_all and stop_all methods
File: `src/network/streaming/stream_manager.rs`

```rust
impl StreamManager {
    /// Start all streams.
    ///
    /// Launches message events, presence, and user events streams.
    /// Each stream runs in its own tokio task.
    ///
    /// # Errors
    ///
    /// Returns error if pool is not connected.
    pub async fn start_all(&self) -> Result<(), NetworkError> {
        if !self.pool.is_connected() {
            return Err(NetworkError::ConnectionFailed(
                "pool not connected".to_string(),
            ));
        }

        // Start message events stream (includes typing, reactions, read receipts)
        self.start_message_events_stream().await?;

        // Start presence stream
        self.start_presence_stream().await?;

        Ok(())
    }

    /// Stop all running streams.
    ///
    /// Sends shutdown signal and waits for tasks to complete.
    pub async fn stop_all(&self) {
        // Signal all streams to stop
        let _ = self.shutdown.send(());

        // Take all handles
        let handles = {
            let mut locked = self.handles.lock();
            std::mem::take(&mut *locked)
        };

        // Wait for each to finish
        if let Some(h) = handles.message_events {
            h.stop();
        }
        if let Some(h) = handles.presence {
            h.stop();
        }
        if let Some(h) = handles.user_events {
            h.stop();
        }
    }

    /// Restart all streams (for reconnection).
    pub async fn restart_all(&self) -> Result<(), NetworkError> {
        self.stop_all().await;
        self.start_all().await
    }
}
```

### Task 5: Implement message events stream starter
File: `src/network/streaming/stream_manager.rs`

```rust
use tokio_stream::StreamExt;
use crate::network::grpc::message_client::MessageClient;
use crate::proto::chat_v1::message_event::Event as MessageEventType;

impl StreamManager {
    /// Start the message events stream.
    ///
    /// This stream receives all message-related events including:
    /// - New messages, edits, deletions
    /// - Reactions added/removed
    /// - Typing indicators
    /// - Read receipts
    async fn start_message_events_stream(&self) -> Result<(), NetworkError> {
        let channel = self.pool.channel();
        let auth = self.pool.auth_clone();
        let mut shutdown_rx = self.shutdown_receiver();

        let (shutdown_tx, shutdown_oneshot) = oneshot::channel();

        let task = tokio::spawn(async move {
            let mut client = MessageClient::new(channel, auth);

            // Start global events stream (all user's channels)
            let stream_result = client.stream_global_events(vec![], None).await;

            let mut stream = match stream_result {
                Ok(s) => s,
                Err(e) => {
                    tracing::error!("Failed to start message events stream: {}", e);
                    return;
                }
            };

            loop {
                tokio::select! {
                    // Check for shutdown signal
                    _ = shutdown_rx.recv() => {
                        tracing::debug!("Message events stream shutting down");
                        break;
                    }
                    _ = async { shutdown_oneshot.await.ok() } => {
                        tracing::debug!("Message events stream stopped via handle");
                        break;
                    }
                    // Process stream events
                    item = stream.next() => {
                        match item {
                            Some(Ok(event)) => {
                                Self::handle_message_event(event);
                            }
                            Some(Err(e)) => {
                                tracing::warn!("Message events stream error: {}", e);
                                // Stream will likely end, break to trigger reconnect
                                break;
                            }
                            None => {
                                tracing::info!("Message events stream ended");
                                break;
                            }
                        }
                    }
                }
            }
        });

        let handle = StreamHandle::new(task, shutdown_tx);
        self.handles.lock().message_events = Some(handle);

        Ok(())
    }

    /// Handle a message event from the stream.
    fn handle_message_event(event: crate::proto::chat_v1::MessageEvent) {
        // Log for now - in future plans, events will be dispatched to EventBus
        match event.event {
            Some(MessageEventType::MessageSent(msg)) => {
                tracing::debug!("Received message: {} in channel {}", msg.id, msg.channel_id);
            }
            Some(MessageEventType::MessageUpdated(msg)) => {
                tracing::debug!("Message updated: {}", msg.id);
            }
            Some(MessageEventType::MessageDeletedId(id)) => {
                tracing::debug!("Message deleted: {}", id);
            }
            Some(MessageEventType::ReactionAdded(reaction)) => {
                tracing::debug!("Reaction added to message {}", reaction.message_id);
            }
            Some(MessageEventType::ReactionRemoved(reaction)) => {
                tracing::debug!("Reaction removed from message {}", reaction.message_id);
            }
            Some(MessageEventType::ReadReceipt(receipt)) => {
                tracing::debug!("Read receipt from user {}", receipt.user_id);
            }
            Some(MessageEventType::TypingIndicator(typing)) => {
                tracing::debug!("Typing indicator from user {}", typing.user_id);
            }
            None => {
                tracing::warn!("Empty message event received");
            }
        }
    }
}
```

```rust
impl StreamManager {
    /// Start the presence stream.

        let (shutdown_tx, shutdown_oneshot) = oneshot::channel();

                    return;
                }

                        break;
                    }

                        tracing::debug!("Presence stream stopped via handle");
```
