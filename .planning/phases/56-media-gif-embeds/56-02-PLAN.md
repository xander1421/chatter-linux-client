  <name>Task 1: Implement YouTubeEmbed extractor</name>
  <files>src/media/embed/youtube.rs, src/error/media_error.rs</files>
  <action>Implement YouTube metadata extraction using oEmbed API:

  1. Add EmbedError variant to MediaError if not exists:
     - `EmbedError(String)` - for URL fetch/parse failures

  2. Rename the stub struct to YouTubeExtractor (domain already has YouTubeEmbed):
     - `client: reqwest::Client`

  3. Implement YouTubeExtractor:
     - `new() -> Self` - create with reqwest::Client
     - `async fn extract(&self, url: &str) -> Result<Option<crate::domain::embed::YouTubeEmbed>, MediaError>`
       - Extract video_id using `crate::domain::embed::YouTubeEmbed::extract_video_id(url)`
       - If None, return Ok(None)
       - Fetch oEmbed: GET `https://www.youtube.com/oembed?url={url}&format=json`
       - Parse JSON response for: title, author_name (channel), thumbnail_url
       - Construct YouTubeEmbed using domain type's constructor
       - Return Ok(Some(embed))

  4. oEmbed response structure:
     ```json
     {
       "title": "Video Title",
       "author_name": "Channel Name",
       "thumbnail_url": "https://i.ytimg.com/vi/ID/hqdefault.jpg",
       "width": 480,
       "height": 270
     }
     ```

  5. Fallback if oEmbed fails:
     - Still return YouTubeEmbed with video_id
     - Use default thumbnail: `https://i.ytimg.com/vi/{video_id}/hqdefault.jpg`
     - Title = "YouTube Video" (placeholder)

  Avoid: Parsing HTML (use oEmbed API only). Don't fetch video duration (requires YouTube Data API with key).</action>
  <verify>cargo check --lib passes, YouTubeExtractor compiles</verify>
  <done>YouTubeExtractor can fetch YouTube video metadata via oEmbed</done>
</task>

<task type="auto">
  <name>Task 2: Implement LinkPreviewGenerator for OpenGraph</name>
  <files>src/media/embed/link_preview.rs</files>
  <action>Implement generic link preview extraction via OpenGraph meta tags:

  1. Create LinkPreviewGenerator struct:
     - `client: reqwest::Client`

  2. Implement methods:
     - `new() -> Self` - create with reqwest::Client configured with:
       - timeout: 10 seconds
       - redirect policy: limited (max 5)
       - User-Agent: "ChatterBot/1.0"
     - `async fn generate(&self, url: &str) -> Result<crate::domain::embed::LinkPreview, MediaError>`
       - Fetch URL with GET request
       - Parse HTML response for OpenGraph meta tags
       - Return LinkPreview from domain module

  3. OpenGraph tag parsing (simple string search, no HTML parser):
     - og:title: `<meta property="og:title" content="..."`
     - og:description: `<meta property="og:description" content="..."`
     - og:image: `<meta property="og:image" content="..."`
     - og:site_name: `<meta property="og:site_name" content="..."`
     - Fallback to `<title>` tag if no og:title

  4. Create helper function `extract_meta_content(html: &str, property: &str) -> Option<String>`:
     - Search for `property="{property}"` or `name="{property}"`
     - Extract content attribute value
     - Handle both single and double quotes
     - Decode basic HTML entities (&amp;, &lt;, &gt;, &quot;)

  5. Favicon extraction (bonus):
     - Look for `<link rel="icon"` or `<link rel="shortcut icon"`
     - If not found, try `/favicon.ico` at domain root

  Avoid: Full HTML parsing library (use simple string matching). Don't follow JavaScript redirects. Limit response body to first 100KB.</action>
  <verify>cargo check --lib passes, LinkPreviewGenerator compiles</verify>
  <done>LinkPreviewGenerator can extract OpenGraph metadata from URLs</done>
</task>

  <files>src/media/embed/unfurl.rs, src/media/embed/mod.rs, src/media/mod.rs</files>
  <action>Implement UrlUnfurler that routes URLs to appropriate extractors:

  1. Create UrlUnfurler struct:
     - `youtube: YouTubeExtractor`
     - `link_preview: LinkPreviewGenerator`

  2. Implement methods:
     - `new() -> Self` - create extractors
     - `async fn unfurl(&self, url: &str) -> Result<crate::domain::embed::LinkEmbed, MediaError>`
       - Use `LinkEmbed::detect_type(url)` from domain module
       - Match on EmbedType:
         - YouTube → use youtube.extract(), wrap in LinkEmbed::YouTube
         - Image → return LinkEmbed::Image { url, width: None, height: None }
         - Twitter → return LinkEmbed::Generic (Twitter API requires auth)
         - GitHubRepo/Issue/PR → return LinkEmbed::Generic (GitHub API available but complex)
         - Generic → use link_preview.generate(), wrap in LinkEmbed::Generic
     - `async fn unfurl_batch(&self, urls: &[&str]) -> Vec<Result<crate::domain::embed::LinkEmbed, MediaError>>`
       - Process URLs concurrently with futures::future::join_all
       - Return results in same order as input

  4. Update src/media/mod.rs:
     - Add re-exports from embed module:
