Implement RetryExecutor that wraps async operations with retry logic:

```rust
pub struct RetryExecutor {
    policy: RetryPolicy,
}

impl RetryExecutor {
    pub fn new(policy: RetryPolicy) -> Self;

    /// Execute an async operation with retry.
    ///
    /// The operation is called repeatedly until:
    /// - It succeeds (returns Ok)
    /// - It fails with a non-retryable error
    /// - Maximum attempts are exhausted
    ///
    /// Returns the operation result or the last error.
    pub async fn execute<F, Fut, T, E>(&self, operation: F) -> Result<T, E>
    where
        F: Fn() -> Fut,
        Fut: std::future::Future<Output = Result<T, E>>,
        E: Into<NetworkError> + From<NetworkError> + Clone;

    /// Execute with a custom retry predicate.
    pub async fn execute_with<F, Fut, T, E, P>(&self, operation: F, should_retry: P) -> Result<T, E>
    where
        F: Fn() -> Fut,
        Fut: std::future::Future<Output = Result<T, E>>,
        P: Fn(&E, usize) -> bool;
}
```

Implementation notes:
- Create a FibonacciBackoff instance from policy.timeouts
- Loop: call operation, on error check should_retry, sleep with backoff.next(), repeat
- Track attempt count starting at 1
- On non-retryable error or exhausted attempts, return the error
- Use tokio::time::sleep for delays

DO NOT use exponential backoff - use the existing FibonacciBackoff from recovery.rs.
