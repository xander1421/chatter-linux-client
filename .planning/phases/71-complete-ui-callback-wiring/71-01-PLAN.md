Wire these callbacks:

1. **channel-selected**:
   - Update `chat_state.set_active_channel(channel_id)`
   - Fetch messages via message_service.get_messages() for that channel
   - Update window properties: channel-id, channel-name, messages array
   - Use invoke_from_event_loop for UI updates from async

2. **dm-selected**:
   - Similar to channel-selected but sets selected-dm-id
   - DMs are channels with type "dm"

3. **saved-messages-clicked**:
   - Set a special channel ID or flag for saved messages view
   - Fetch saved messages via saved_message_service

4. **settings-clicked**:
   - Simply set `window.set_active_modal("settings".into())`
   - No async needed, synchronous UI update

5. **profile-clicked**:
   - Get current user from auth_state
   - Populate profile modal properties (profile-user-id, profile-display-name, etc.)
   - Set profile-is-self to true
   - Set `window.set_active_modal("user-profile".into())`

Pattern: Clone needed Arc references before callbacks. Use tokio::spawn for async work. Use invoke_from_event_loop for UI updates.
