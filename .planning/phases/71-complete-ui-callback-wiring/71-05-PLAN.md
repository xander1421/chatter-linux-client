Helper for initials:
```rust
fn get_initials(name: &str) -> String {
    name.split_whitespace()
        .filter_map(|word| word.chars().next())
        .take(2)
        .collect::<String>()
        .to_uppercase()
}
```

When the app reconnects after being offline:
1. Subscribe to connection state changes from grpc_pool
2. On reconnect, refresh channel list and unread counts
3. Sync any pending offline messages

Add to main():
```rust
// Subscribe to connection events
let conn_rx = ctx.grpc_pool.subscribe_connection();
let weak_window = window.as_weak();
let ctx_clone = ctx.clone(); // Need to make ctx clonable or extract needed fields
tokio::spawn(async move {
    while let Ok(event) = conn_rx.recv().await {
        if event == ConnectionEvent::Connected {
            load_initial_data(weak_window.clone(), &ctx_clone).await;
        }
    }
});
```

This ensures data stays fresh and handles offline→online transitions.
