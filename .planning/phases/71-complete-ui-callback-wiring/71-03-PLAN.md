<task type="auto">
  <name>Task 1: Wire create-channel callback</name>
  <files>src/main.rs</files>
  <action>
Create `wire_modal_callbacks(window: &MainWindow, ctx: &AppContext)`.

**create-channel(name, description, template)**:
1. Set create-channel-loading = true
2. Create ChannelClient from grpc_pool
3. Map template string to ChannelType:
   - "general" -> Public
   - "project" -> Private
   - "announcement" -> Public with restricted posting
   - "ephemeral" -> Private with TTL
4. Call channel_service.create_channel()
5. On success:
   - Add channel to local repo
   - Close modal (active-modal = "none")
   - Clear form fields
   - Select new channel
6. On error:
   - Set create-channel-error with message
   - Set create-channel-loading = false

Pattern: Use the same async spawn + invoke_from_event_loop pattern as auth callbacks.
  </action>
  <verify>cargo build succeeds</verify>
  <done>create-channel creates channel and updates UI</done>
</task>

<task type="auto">
  <name>Task 2: Wire user profile callbacks</name>
  <files>src/main.rs</files>
  <action>
**profile-send-message()**:
- Get profile-user-id from window
- Find or create DM channel with user
- Close modal
- Navigate to DM (call dm-selected logic)

**profile-add-friend()**:
- Set profile-loading = true
- Call user_service.send_friend_request(user_id)
- On success: Update profile-is-friend state, show toast
- On error: Show toast with error

**profile-remove-friend()**:
- Confirm action (or just execute)
- Call user_service.remove_friend(user_id)
- Update profile-is-friend = false

**profile-block-user()**:
- Call user_service.block_user(user_id)
- Update profile-is-blocked = true
- Close modal

**profile-unblock-user()**:
- Call user_service.unblock_user(user_id)
- Update profile-is-blocked = false
  </action>
  <verify>cargo build succeeds</verify>
  <done>Profile modal actions work correctly</done>
</task>

<task type="auto">
  <name>Task 3: Wire friend requests and forward callbacks</name>
  <files>src/main.rs</files>
  <action>
**friend-requests-switch-tab(tab)**:
- Set friend-requests-tab property
- Refresh appropriate list (received or sent)
- No async needed for tab switch itself

**friend-request-accept(user_id)**:
- Set friend-requests-loading = true
- Call user_service.respond_friend_request(user_id, Accept)
- Remove from received-requests array
- Show success toast

**friend-request-decline(user_id)**:
- Call user_service.respond_friend_request(user_id, Decline)
- Remove from received-requests array

**friend-request-cancel(user_id)**:
- Call user_service.cancel_friend_request(user_id)
- Remove from sent-requests array

**forward-message(target_id)**:
- Set forward-loading = true
- Get message to forward from state
- Call forward_service.forward_message(message_id, target_id)
- Close modal on success
- Show toast confirmation
  </action>
  <verify>cargo build succeeds</verify>
  <done>Friend requests and forwarding functional</done>
