**Callbacks to wire (11):**
Settings account:
- settings-edit-profile() - Navigate to profile edit (or open modal)
- settings-change-password(current, new) - Change password
- settings-view-sessions() - Open sessions modal
- settings-delete-account() - Delete account (with confirmation)

Settings privacy:
- settings-read-receipts-changed(bool) - Toggle read receipts
- settings-typing-indicators-changed(bool) - Toggle typing indicators

Settings encryption:
- settings-copy-fingerprint() - Copy identity fingerprint to clipboard
- settings-sealed-sender-changed(bool) - Toggle unrestricted sealed sender
- settings-refresh-keys() - Generate new prekeys

Sessions modal:
- revoke-session(device_id) - Revoke a specific session
- revoke-all-sessions() - Revoke all other sessions

Note: settings-logout already wired in auth callbacks.
</context>

<tasks>

<task type="auto">
  <name>Task 1: Wire settings account callbacks</name>
  <files>src/main.rs</files>
  <action>
Create `wire_settings_callbacks(window: &MainWindow, ctx: &AppContext)`.

**settings-edit-profile()**:
- Open profile edit modal or switch to edit view
- For v1, could just close settings and open profile modal with is-self=true

**settings-change-password(current, new)**:
- Set settings-password-changing = true
- Validate: new password meets requirements, current not empty
- Call account_service.change_password(current, new)
- On success: Clear password fields, show success toast
- On error: Set settings-password-error with message

**settings-view-sessions()**:
- Set sessions-loading = true
- Call session_service.list_sessions()
- Populate sessions array
- Set active-modal = "sessions"

**settings-delete-account()**:
- This is destructive - consider confirmation flow
- For v1, call account_service.delete_account()
- On success: Logout and return to login screen
- On error: Show error toast
  </action>
  <verify>cargo build succeeds</verify>
  <done>Account settings callbacks functional</done>
</task>

<task type="auto">
  <name>Task 2: Wire privacy and encryption callbacks</name>
  <files>src/main.rs</files>
  <action>
**settings-read-receipts-changed(enabled)**:
- Update settings_repo.set_read_receipts(enabled)
- Update privacy_state

**settings-typing-indicators-changed(enabled)**:
- Update settings_repo.set_typing_indicators(enabled)
- Update privacy_state

**settings-copy-fingerprint()**:
- Get identity fingerprint from identity_manager
- Use clipboard::copy_to_clipboard(fingerprint)
- Show toast "Fingerprint copied"

**settings-sealed-sender-changed(enabled)**:
- Update settings_repo.set_unrestricted_sealed_sender(enabled)
- Sync preference to server

**settings-refresh-keys()**:
- Call prekey_manager.generate_prekeys(count: 100)
- Upload to server via auth_client.upload_prekey_bundle()
- Update settings-prekey-count display
- Show toast "Keys refreshed"
  </action>
