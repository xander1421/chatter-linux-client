Create migration v015_ephemeral_messages.rs that adds an ephemeral_messages table:

```sql
CREATE TABLE ephemeral_messages (
    message_id TEXT PRIMARY KEY REFERENCES messages(id) ON DELETE CASCADE,
    ttl_seconds INTEGER NOT NULL,
    expires_at TEXT NOT NULL,  -- RFC3339
    read_at TEXT,              -- RFC3339, NULL until read
    countdown_started INTEGER NOT NULL DEFAULT 0
);

-- Index for cleanup queries (find expired messages)
CREATE INDEX idx_ephemeral_expires ON ephemeral_messages(expires_at)
    WHERE countdown_started = 1;

-- Index for unread ephemeral messages (pending countdown)
CREATE INDEX idx_ephemeral_pending ON ephemeral_messages(message_id)
    WHERE countdown_started = 0;
```

Register the migration in mod.rs migrations list.

Why separate table: Keeps ephemeral tracking isolated from main message table, enables efficient cleanup queries without scanning all messages, and matches the pattern from domain entity (EphemeralMessage wraps MessageId).

```rust
pub struct EphemeralRepository {

impl EphemeralRepository {
    pub fn new(db: Arc<Database>) -> Self;

    // Insert ephemeral tracking for a message
    pub fn insert(&self, ephemeral: &EphemeralMessage) -> Result<(), StorageError>;

    // Get ephemeral state for a message
    pub fn get(&self, message_id: &MessageId) -> Result<Option<EphemeralMessage>, StorageError>;

    // Mark message as read (starts countdown)
    pub fn mark_read(&self, message_id: &MessageId) -> Result<(), StorageError>;

    // List all expired messages (countdown_started=1 AND expires_at < now)
    pub fn list_expired(&self) -> Result<Vec<MessageId>, StorageError>;

    // Delete ephemeral tracking (after message deletion)
    pub fn delete(&self, message_id: &MessageId) -> Result<(), StorageError>;

    // List pending (unread) ephemeral messages
    pub fn list_pending(&self) -> Result<Vec<EphemeralMessage>, StorageError>;
}
```

Key implementation details:
- Use `chrono::Utc::now()` for current time in `list_expired`
- Convert `MessageTTL` to seconds for storage (`ttl.as_secs()`)
- Convert back using `MessageTTL::from_secs()` (may be None for non-standard TTL)
- `mark_read` should update `read_at = now`, `countdown_started = 1`, recalculate `expires_at = now + ttl_seconds`

Export from mod.rs.
