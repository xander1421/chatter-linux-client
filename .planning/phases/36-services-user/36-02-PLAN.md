Add send_friend_request method:

```rust
pub async fn send_friend_request(
    &self,
    user_client: &mut UserClient,
    friend_id: &UserId,
    message: Option<&str>,
) -> Result<Friendship, UserError>
```

Implementation:
1. Check logged in
2. Call user_client.send_friend_request(&friend_id.to_string(), message).await
3. Consume stream looking for UserEvent with friend_request_sent variant
4. Create local Friendship with status Pending
5. Insert to local storage (ignore if already exists)
6. Return Friendship

Add respond_friend_request method:

```rust
pub async fn respond_friend_request(
    &self,
    user_client: &mut UserClient,
    friend_id: &UserId,
    accept: bool,
) -> Result<Option<Friendship>, UserError>
```

Implementation:
1. Check logged in
2. Determine FriendStatus: Accepted if accept=true, Declined if false
3. Call user_client.respond_friend_request(&friend_id.to_string(), status, None).await
4. Consume stream for confirmation event
5. If accepted: upsert friendship with Accepted status, return Some(Friendship)
6. If declined: delete friendship from local storage if exists, return None

Add helper proto_friend_status_to_domain(status: i32) -> FriendshipStatus for use in event parsing:
- 3 = Accepted
- 4 = Declined
- Others -> Pending
