# Plan 91-01: Multi-Device Encryption for Groups and DMs

## Context

Multi-device infrastructure EXISTS (`encrypt_message_all_devices()` in `signal_service.rs` and `pairwise.rs`) but isn't wired up in all message paths. Currently:

- **dm.rs:115** - CORRECT - Already uses `encrypt_message_all_devices()`
- **group.rs:808** - WRONG - Hardcodes `device_id = 1`
- **core.rs:622** - WRONG - Hardcodes `device_id = 1` for channel DMs
- **dm_bootstrap_service.rs:67** - WRONG - Hardcodes `device_id = 1`

This plan fixes the three broken paths to use all-device encryption.

## Scope

- **Files**: 3 modified
- **Checkpoints**: 3
- **Risk**: Low (infrastructure exists, just wiring changes)

## Checkpoints

### Checkpoint 1: Group Message Multi-Device

**File**: `src/services/message/group.rs`

**Changes**:
1. Replace single-device encryption loop with all-devices call
2. Change HashMap from `HashMap<UserId, Vec<u8>>` to `HashMap<UserId, HashMap<u32, Vec<u8>>>`
3. Update fanout to send separate mailbox messages per device

**Before** (lines 801-827):
```rust
for member_id in group_state.member_mailboxes.keys().copied() {
    let member_id: UserId = member_id;
    match self
        .signal_service
        .encrypt_message(
            auth_client,
            &member_id.to_string(),
            1, // Primary device - group multi-device not yet implemented
            plaintext,
        )
        .await
    {
        Ok(sealed_ciphertext) => {
            member_ciphertexts.insert(member_id, sealed_ciphertext);
            success_count += 1;
        }
        ...
    }
}
```

**After**:
```rust
for member_id in group_state.member_mailboxes.keys().copied() {
    let member_id: UserId = member_id;
    match self
        .signal_service
        .encrypt_message_all_devices(
            auth_client,
            &member_id.to_string(),
            plaintext,
        )
        .await
    {
        Ok(device_ciphertexts) => {
            // device_ciphertexts: HashMap<u32, Vec<u8>> (device_id -> ciphertext)
            let device_count = device_ciphertexts.len();
            member_ciphertexts.insert(member_id, device_ciphertexts);
            success_count += device_count;
        }
        Err(e) => {
            tracing::warn!(
                channel_id = %channel_id,
                member_id = %member_id,
                error = %e,
                "Failed to encrypt for member's devices"
            );
            error_count += 1;
        }
    }
}
```

**Fanout change** (around line 850+):
Update the mailbox fanout loop to iterate over devices:
```rust
for (member_id, device_ciphertexts) in member_ciphertexts {
    let mailbox_pk = match group_state.member_mailboxes.get(&member_id) {
        Some(mb) => &mb.public_key,
        None => continue,
    };

    for (device_id, signal_ciphertext) in device_ciphertexts {
        // Each device gets its own mailbox message
        let mailbox_encrypted = encrypt_dm_bytes(&signal_ciphertext, &group_shared_secret)
            .map_err(|e| MessageError::EncryptionFailed(format!("Group mailbox: {}", e)))?;

        mailbox_manager
            .send_to_mailbox(mailbox_pk, mailbox_encrypted, EnvelopeType::SealedSender)
            .await
            .map_err(|e| MessageError::GroupError(format!("Fanout failed: {}", e)))?;
    }
}
```

### Checkpoint 2: Channel DM Multi-Device

**File**: `src/services/message/core.rs`

**Changes**:
1. Update channel DM encryption to use all-devices
2. Handle multiple ciphertexts - send to primary for server fanout

**Before** (lines 617-634):
```rust
if is_dm {
    if let Ok(recipient_id) = channel_id.to_string().parse::<uuid::Uuid>() {
        match self.signal_service.encrypt_message(
            auth_client,
            &recipient_id.to_string(),
            1, // Primary device - server handles fanout for channel DMs
            plaintext
        ).await {
```

**After**:
```rust
if is_dm {
    if let Ok(recipient_id) = channel_id.to_string().parse::<uuid::Uuid>() {
        // Encrypt for ALL recipient devices (Signal multi-device)
        match self.signal_service.encrypt_message_all_devices(
            auth_client,
            &recipient_id.to_string(),
            plaintext
        ).await {
            Ok(device_ciphertexts) => {
                // For channel DMs, we need to send each device's ciphertext
                // Server handles device addressing via the channel
                // Use primary device (1) as fallback if present, otherwise first
                let primary_ciphertext = device_ciphertexts.get(&1)
                    .or_else(|| device_ciphertexts.values().next())
                    .cloned();

                if let Some(ciphertext) = primary_ciphertext {
                    // Log multi-device encryption
                    tracing::debug!(
                        recipient = %recipient_id,
                        device_count = device_ciphertexts.len(),
                        "Channel DM encrypted for devices"
                    );

                    let encrypted_content = chat_v1::message::Content {
                        r#type: Some(chat_v1::message::content::Type::SealedSender(
                            chat_v1::SealedSenderMessage {
                                sealed_body: ciphertext,
                                ..Default::default()
                            }
                        )),
                    };
                    return (encrypted_content, None);
                }
            },
```

**Note**: Channel DMs differ from mailbox DMs. For channels:
- Server manages device routing via channel subscription
- We encrypt for all devices but send the primary device's ciphertext
- Server fans out to other devices (if supported)

If true multi-device fanout is needed at channel level, server changes required.

### Checkpoint 3: Bootstrap Session Recovery Multi-Device

**File**: `src/services/dm_bootstrap_service.rs`

**Changes**:
1. Update `handle_convergence_failure` to reset sessions for all devices

**Before** (lines 65-68):

**After**:

```rust
    .await
```

**Requires adding to MessageService** (`src/services/message/mod.rs` or core):
```rust
/// Reset and establish sessions for all devices of a peer.
pub async fn reset_and_establish_sessions_all_devices(
    &self,
    auth_client: &mut AuthClient,
    peer_id: &UserId,
) -> Result<Vec<u32>, ServiceError> {
    let peer_id_str = peer_id.to_string();

    // Get all device IDs for peer
    let device_ids = self.signal_service
        .ensure_sessions_all_devices(auth_client, &peer_id_str)
        .await?;

    tracing::info!(
        peer_id = %peer_id,
        device_count = device_ids.len(),
        "Reset sessions for all peer devices"
    );

    Ok(device_ids)
}
```
