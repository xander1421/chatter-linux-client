# Plan 91-02: SentTranscript Sync for Saved Messages

## Context

Signal Protocol uses "SentTranscript" messages to sync sent messages across linked devices. When device A sends a message, it also sends a SentTranscript to devices B, C, etc. so they can display the message in their local chat history.

Currently, Saved Messages (`saved.rs`) only stores locally and logs a warning about missing multi-device sync.

## Scope

- **Files**: 4 modified, 1 new proto
- **Checkpoints**: 3
- **Risk**: Medium (requires proto definition, new inbox handler)

## Prerequisites

- Plan 91-01 complete (multi-device encryption working)

### Checkpoint 1: Define SentTranscript Proto

**File**: `pkg/proto/content_v1/sync.proto` (or add to existing content.proto)

**New message definition**:
```protobuf
// SentTranscript - Sync sent messages to other linked devices
// Per Signal Protocol, this allows all devices to show the same chat history
message SentTranscript {
  // Original message that was sent
  string message_id = 1;

  // Destination (channel ID or user ID for DM)
  string destination_id = 2;

  // Timestamp when original message was sent (millis)
  uint64 sent_timestamp = 3;

  // The original message content (encrypted for this device)
  message.Content content = 4;

  // For DMs: the recipient's user ID
  optional string recipient_id = 5;

  // Expiration timer if set
  optional uint32 expiration_seconds = 6;
}

// SyncMessage envelope - wraps different sync types
message SyncMessage {
  oneof sync_type {
    SentTranscript sent = 1;
    // Future: ReadSync, ViewedSync, etc.
  }
}
```

**Add helper method**:
```rust
/// Send a SentTranscript to a specific linked device.
async fn send_sync_to_device(
    &self,
    auth_client: &mut AuthClient,
    local_user_id: &UserId,
    device_id: u32,
    transcript: &SentTranscript,
) -> Result<(), MessageError> {
    use prost::Message;

    // Wrap in SyncMessage
    let sync_message = SyncMessage {
        sync_type: Some(sync_message::SyncType::Sent(transcript.clone())),
    };

    // Serialize
    let plaintext = sync_message.encode_to_vec();

    // Encrypt for self (same user, different device)
    let ciphertext = self.signal_service
        .encrypt_message(
            auth_client,
            &local_user_id.to_string(),
            device_id,
            &plaintext,
        )
        .await
        .map_err(|e| MessageError::EncryptionFailed(format!("Sync encrypt: {}", e)))?;

    // Send via device queue (requires server support)
    // For now, use mailbox system if available, or defer to server
    self.mailbox_manager
        .send_sync_to_device(local_user_id, device_id, ciphertext)
        .await
        .map_err(|e| MessageError::NetworkError(format!("Sync send: {}", e)))?;

    Ok(())
}
```

### Checkpoint 3: Handle Incoming SentTranscript

**File**: `src/inbox/handlers/sync.rs`

**Add SentTranscript handler**:
```rust
/// Handle incoming SentTranscript - store the sent message locally.
pub async fn handle_sent_transcript(
    context: &HandlerContext,
    transcript: SentTranscript,
) -> Result<Option<DomainEvent>, ProcessingError> {
    tracing::info!(
        message_id = %transcript.message_id,
        destination = %transcript.destination_id,
        "Received SentTranscript from linked device"
    );

    // Parse IDs
    let message_id = transcript.message_id.parse()
        .map_err(|_| ProcessingError::InvalidFormat("Invalid message_id".into()))?;
    let channel_id = transcript.destination_id.parse()
        .map_err(|_| ProcessingError::InvalidFormat("Invalid destination_id".into()))?;

    // Reconstruct message from transcript
    let sender_id = context.local_user_id;
    let sent_at = transcript.sent_timestamp;

    let content = transcript.content
        .ok_or_else(|| ProcessingError::InvalidFormat("Missing content".into()))?;

    // Convert proto content to domain message
    let message = Message::from_transcript(
        message_id,
        channel_id,
        sender_id,
        sent_at,
        content,
    )?;

    // Store locally (idempotent - skip if exists)
    match context.message_repo.insert_or_ignore(&message) {
        Ok(true) => {
            tracing::info!(
                message_id = %message.id,
                "SentTranscript: stored synced message"
            );
            // Emit event for UI update
            Ok(Some(DomainEvent::MessageReceived {
                message_id: message.id,
                channel_id: message.channel_id,
            }))
        }
        Ok(false) => {
            tracing::debug!(
                message_id = %message.id,
                "SentTranscript: message already exists locally"
            );
            Ok(None)
        }
        Err(e) => {
            tracing::error!(
                message_id = %message.id,
                error = %e,
                "SentTranscript: failed to store message"
            );
            Err(ProcessingError::StorageError(e.to_string()))
        }
    }
}
```
