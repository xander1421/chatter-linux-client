  <name>Task 1: Create AppContext struct with lazy initialization</name>

  <action>
Create src/app/context.rs with an AppContext struct that holds all application dependencies:

```rust
pub struct AppContext {
    // System
    pub directories: Directories,
    pub keyring: Keyring,

    // Storage
    pub database: Arc<Database>,
    pub key_store: Arc<KeyStore>,

    // Repositories (all Arc for sharing)
    pub user_repo: Arc<UserRepository>,
    pub channel_repo: Arc<ChannelRepository>,
    pub message_repo: Arc<MessageRepository>,
    pub settings_repo: Arc<SettingsRepository>,
    pub attachment_repo: Arc<AttachmentRepository>,
    pub reaction_repo: Arc<ReactionRepository>,
    pub draft_repo: Arc<DraftRepository>,

    // Crypto managers
    pub identity_manager: Arc<IdentityKeyManager>,
    pub prekey_manager: Arc<PreKeyManager>,
    pub session_manager: Arc<SessionManager>,
    pub sender_key_manager: Arc<SenderKeyManager>,

    // Network
    pub grpc_pool: Arc<GrpcClientPool>,
    pub auth_interceptor: AuthInterceptor,
}
```

Implement AppContext::new() that:
1. Creates Directories (ensures XDG paths exist)
2. Creates Keyring
3. Gets or generates database passphrase from keyring
4. Opens Database with passphrase and runs migrations
5. Creates KeyStore from database
6. Creates all repositories with Arc<Database>
7. Creates crypto managers with Arc<KeyStore>
8. Creates GrpcClientPool with server URL from env or default
9. Gets AuthInterceptor from pool

Add AppContext::passphrase_or_generate() helper that:
- Tries keyring.get_passphrase()
- If not found, generates random 32-byte hex passphrase
- Stores in keyring and returns it

Update src/app/mod.rs to export context module.

Server URL should come from CHATTER_SERVER_URL env var, default to "http://localhost:50051".

Add method to create AuthService:

```rust
impl AppContext {
    /// Creates an AuthService with all required dependencies.
    pub fn auth_service(&self) -> AuthService {
        AuthService::new(
            self.identity_manager.clone(),
            self.prekey_manager.clone(),
            self.user_repo.clone(),
            self.settings_repo.clone(),
            self.key_store.clone(),
            self.auth_interceptor.clone(),
        )
    }

    /// Creates an AuthClient connected to the server.
    ///
    /// # Panics
    ///
    /// Panics if grpc_pool is not connected.
    pub fn auth_client(&self) -> AuthClient {
        AuthClient::new(
            self.grpc_pool.channel(),
            self.auth_interceptor.clone(),
        )
    }
}
```

This allows main.rs to easily get the services it needs.
