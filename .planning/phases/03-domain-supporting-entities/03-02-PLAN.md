<task type="auto">
  <name>Task 1: Implement Call, Participant, and VerificationBadge entities</name>
  <files>src/domain/call.rs</files>
  <action>
Replace stub with full implementation:

**CallType enum:**
- Voice, Video, Group

**CallState enum** (expand existing stub):
- Initiating - call being set up
- Ringing - recipient's device ringing
- Connecting - establishing connection
- Connected - call active
- Reconnecting - temporary connection loss
- Ended { reason: CallEndReason } - call finished

**CallEndReason enum:**
- Completed, Declined, Missed, Busy, Failed, NetworkError

**Call struct:**
- id: CallId
- channel_id: ChannelId
- initiator_id: UserId
- call_type: CallType
- state: CallState
- participants: Vec<Participant>
- started_at: Option<DateTime<Utc>>
- connected_at: Option<DateTime<Utc>>
- ended_at: Option<DateTime<Utc>>
- is_encrypted: bool
- Helper: new(channel_id, initiator_id, call_type) -> Call in Initiating state
- Helper: start(&mut self) - transition to Connected, set connected_at
- Helper: end(&mut self, reason: CallEndReason) - set ended_at, state to Ended
- Helper: duration() -> Option<Duration> - time between connected_at and ended_at (or now if active)
- Helper: is_active() -> bool - true if Connected or Reconnecting
- Helper: add_participant(&mut self, participant: Participant)
- Helper: remove_participant(&mut self, user_id: UserId)

**Participant struct:**
- user_id: UserId
- joined_at: DateTime<Utc>
- is_muted: bool
- is_video_enabled: bool
- is_screen_sharing: bool
- Helper: new(user_id) -> Participant with defaults (not muted, video off, no screen share)
- Helper: toggle_mute(&mut self)
- Helper: toggle_video(&mut self)

**VerificationBadge struct** (E2EE call verification display):
- safety_number: String (truncated for display)
- is_verified: bool
- last_verified_at: Option<DateTime<Utc>>
- Helper: new(safety_number) -> unverified badge
- Helper: verify(&mut self) - mark as verified with timestamp
- Helper: display_code() -> String - formatted safety number for UI (space-separated groups)

Add imports: chrono (DateTime, Duration, Utc), serde, crate::domain::ids (CallId, ChannelId, UserId)

**ModerationAction enum:**
- Ban, Mute, Kick, Warn

**Ban struct:**
- id: Uuid (no special BanId type needed - internal use)
- channel_id: ChannelId
- user_id: UserId (banned user)
- banned_by: UserId (moderator)
- reason: Option<String>

- created_at: DateTime<Utc>
- Helper: new(channel_id, user_id, banned_by) -> permanent ban
- Helper: with_expiry(mut self, duration: Duration) -> Self
- Helper: with_reason(mut self, reason: String) -> Self
- Helper: is_expired() -> bool
- Helper: is_permanent() -> bool

**Mute struct:**
- id: Uuid
- channel_id: ChannelId
- user_id: UserId (muted user)
- muted_by: UserId (moderator)
- reason: Option<String>
- expires_at: DateTime<Utc> (mutes always have expiry)
- created_at: DateTime<Utc>
- Helper: new(channel_id, user_id, muted_by, duration: Duration)
- Helper: with_reason(mut self, reason: String) -> Self
- Helper: is_expired() -> bool
- Helper: time_remaining() -> Option<Duration>

**ModerationLogEntry struct:**
- id: Uuid
- channel_id: ChannelId
- target_user_id: UserId
- moderator_id: UserId
- action: ModerationAction
- reason: Option<String>
- created_at: DateTime<Utc>
- Helper: new(channel_id, target_user_id, moderator_id, action)
