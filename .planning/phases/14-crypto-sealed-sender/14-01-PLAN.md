**Established patterns:**

- Store references passed per-method to avoid mutable aliasing
- CryptoError wrapping libsignal errors via `.to_string()`
- rand::rng() for RNG (not deprecated thread_rng)

**Constraining decisions:**
- Phase 11: Stateless manager design - stores passed per-method
- Phase 13: Consistent stateless pattern across all crypto managers

**libsignal sealed sender API exports:**
- `SenderCertificate` - Certificate identifying sender (signed by server)
- `ServerCertificate` - Server's signing certificate (used to validate sender certs)
- `UnidentifiedSenderMessageContent` - Sealed sender message container
- `SealedSenderDecryptionResult` - Result with sender_uuid, device_id, message
- `ContentHint` - Message type hint (Default, Resendable, Implicit)
- `sealed_sender_encrypt` - Encrypt plaintext to sealed sender format
- `sealed_sender_decrypt` - Decrypt and validate sealed sender message
- `sealed_sender_encrypt_from_usmc` - Encrypt from pre-built USMC
- `sealed_sender_decrypt_to_usmc` - Decrypt to USMC without inner decryption
- `sealed_sender_multi_recipient_encrypt` - Multi-recipient encryption (v2)

<task type="auto">
  <name>Task 2: Implement SealedSenderManager</name>
  <files>src/crypto/signal/sealed_sender.rs</files>
  <action>
Create new file `src/crypto/signal/sealed_sender.rs` with SealedSenderManager struct.

Import from libsignal_protocol:
- SenderCertificate, ServerCertificate, UnidentifiedSenderMessageContent
- SealedSenderDecryptionResult, ContentHint
- sealed_sender_encrypt, sealed_sender_decrypt
- sealed_sender_encrypt_from_usmc, sealed_sender_decrypt_to_usmc
- CiphertextMessageType, ProtocolAddress, PublicKey, DeviceId, Timestamp
- IdentityKeyStore, SessionStore, PreKeyStore, SignedPreKeyStore, KyberPreKeyStore

Implement SealedSenderManager as stateless struct (like SessionManager) with methods:

1. `encrypt()` - Encrypt plaintext to sealed sender format
   - Takes: ptext, sender_cert, recipient_address, stores (session, identity), rng
   - Uses sealed_sender_encrypt
   - Returns encrypted bytes

2. `decrypt()` - Decrypt sealed sender message and validate certificate
   - Takes: ciphertext, trust_root (PublicKey), timestamp, local_e164 (Option), local_uuid, local_device_id, all stores (identity, session, prekey, signed_prekey, kyber_prekey)
   - Uses sealed_sender_decrypt
   - Returns SealedSenderDecryptionResult (re-export from libsignal)

3. `create_content()` - Create UnidentifiedSenderMessageContent from ciphertext message
   - Takes: msg_type, sender_cert, content_bytes, content_hint, group_id (Option)
   - Uses UnidentifiedSenderMessageContent::new
   - Returns the USMC for use with encrypt_from_usmc

4. `encrypt_from_content()` - Encrypt pre-built USMC
   - Takes: usmc, recipient_address, identity_store, rng
   - Uses sealed_sender_encrypt_from_usmc
   - Returns encrypted bytes

5. `decrypt_to_content()` - Decrypt to USMC without inner message decryption
   - Takes: ciphertext, identity_store
   - Uses sealed_sender_decrypt_to_usmc
   - Returns UnidentifiedSenderMessageContent for inspection/forwarding

Use rand::rng() for RNG. Map libsignal errors to CryptoError variants.
  </action>
  <verify>cargo check --lib passes, sealed_sender module compiles</verify>
  <done>SealedSenderManager implemented with all 5 methods, follows stateless pattern</done>
