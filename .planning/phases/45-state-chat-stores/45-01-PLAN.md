**Established patterns (from Phase 44):**
- Store<T> reactive container with parking_lot::RwLock + tokio::broadcast
- Separate data structs (XxxStateData) from state managers (XxxState)
- broadcast channel capacity 16 for UI subscribers
- Store<T> is Clone (shares underlying Arc state)
- Reactive pattern: Store<T>.subscribe() returns broadcast::Receiver

**Constraining decisions:**
- Maximum 3 concurrent threads (from FEATURES.md)
- Drafts keyed by DraftKey (channel + optional thread)
- Cursor-based pagination using (created_at, id) tuple
