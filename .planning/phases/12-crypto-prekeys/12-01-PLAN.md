**Tech stack available:**
- libsignal-protocol (PreKeyRecord, SignedPreKeyRecord, KyberPreKeyRecord, PreKeyBundle, GenericSignedPreKey trait)
- KeyStore with save_prekey, save_signed_prekey, save_kyber_prekey operations
- CryptoError with Storage, Protocol, InvalidKeyFormat variants

**Established patterns:**
- Stateless manager pattern (stores passed per-method)
- StorageCallbackError wrapper for libsignal compatibility
- IdentityKeyManager pattern for key generation/storage

**Constraining decisions:**
- PQXDH-only (libsignal no longer supports X3DH)
- Kyber prekeys are REQUIRED for PreKeyBundle (not optional)
- Registration ID is 14-bit (1-16383)

**libsignal API reference (verified from source):**
- `PreKeyRecord::new(id: PreKeyId, key: &KeyPair)` - one-time prekey
- `SignedPreKeyRecord::new(id, timestamp, &key_pair, &signature)` via GenericSignedPreKey trait
- `KyberPreKeyRecord::generate(kem::KeyType::Kyber1024, id, &signing_key)` - has built-in generate()
- `PreKeyBundle::new(registration_id, device_id, pre_key, signed_pre_key_id, signed_pre_key_public, signed_pre_key_signature, kyber_pre_key_id, kyber_pre_key_public, kyber_pre_key_signature, identity_key)`

  <files>src/crypto/signal/prekey.rs, src/error/crypto_error.rs</files>
  <action>
Replace the stub PreKeyManager with full implementation:

1. Add necessary imports:
   - libsignal_protocol::{PreKeyRecord, PreKeyId, SignedPreKeyRecord, SignedPreKeyId, KyberPreKeyRecord, KyberPreKeyId, KeyPair, IdentityKeyPair, Timestamp, kem, GenericSignedPreKey}
   - rand::{CryptoRng, Rng}
   - std::sync::Arc, std::time::SystemTime
   - crate::storage::KeyStore, crate::error::CryptoError

2. Create PreKeyManager struct wrapping Arc<KeyStore>

3. Implement generate_prekey(rng, id: u32) -> Result<PreKeyRecord>:
   - Generate KeyPair with KeyPair::generate(rng)
   - Create PreKeyRecord::new(PreKeyId::from(id), &key_pair)
   - Store via key_store.save_prekey(id, &record.serialize()?)
   - Return record

4. Implement generate_signed_prekey(rng, id: u32, identity_key_pair: &IdentityKeyPair) -> Result<SignedPreKeyRecord>:
   - Generate KeyPair
   - Calculate signature: identity_key_pair.private_key().calculate_signature(&key_pair.public_key.serialize(), rng)
   - Create timestamp from SystemTime::now()
   - Use SignedPreKeyRecord::new(SignedPreKeyId::from(id), timestamp, &key_pair, &signature)
   - Store via key_store.save_signed_prekey(id, &record.serialize()?)
   - Return record

5. Implement generate_kyber_prekey(id: u32, identity_key_pair: &IdentityKeyPair) -> Result<KyberPreKeyRecord>:
   - Use KyberPreKeyRecord::generate(kem::KeyType::Kyber1024, KyberPreKeyId::from(id), identity_key_pair.private_key())
   - Store via key_store.save_kyber_prekey(id, &record.serialize()?)
   - Return record

6. Implement generate_prekeys(rng, start_id: u32, count: u32) -> Result<Vec<PreKeyRecord>> for batch generation

Remove the stub PreKeyBundle struct (we use libsignal's PreKeyBundle directly).

Add InsufficientPreKeys error variant to CryptoError if not present (for when prekey count is too low).
