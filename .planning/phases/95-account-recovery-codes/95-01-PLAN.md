**Constraining decisions:**
- 8 recovery codes, 8 alphanumeric chars each (base32-like, no ambiguous chars: exclude 0/O/1/I/L)
- Argon2id hash each code individually (server never stores plaintext)
- Each code is one-time use (mark as used after successful verification)
- UseRecoveryCode: verify code → reset password → invalidate code → return new session
- Rate limit: 3 attempts per hour per user
- Codes returned in RegistrationResult (streamed to client once, never retrievable again)
- All Go commands require GOEXPERIMENT=runtimesecret

StoreRecoveryCodes: batch INSERT of 8 hashed codes for a user.
VerifyAndUseRecoveryCode: iterate unused codes, compare each hash, mark used if match, return remaining count. Use the existing Argon2 VerifyPassword function for comparison.
Rate limiting follows the same pattern as SVR fetch attempts.

**Service** — Add methods to auth service (new file `recovery_codes.go`):

```go
func (s *serviceImpl) GenerateRecoveryCodes(ctx context.Context, userID string) ([]string, error)
func (s *serviceImpl) UseRecoveryCode(ctx context.Context, req *chatauth.UseRecoveryCodeRequest) (*UseRecoveryCodeResult, error)
```

GenerateRecoveryCodes:
1. Generate 8 random codes: 8 chars each from alphabet `ABCDEFGHJKMNPQRSTUVWXYZ23456789` (32 chars, no ambiguous 0/O/1/I/L)
2. Hash each with Argon2id using existing crypto.GeneratePassword()
3. Store hashes via repository
4. Return plaintext codes (these go to client, never stored on server)

UseRecoveryCode:
1. Look up user by username (hash username with empty profile key? or use direct lookup — check existing patterns)
2. Check rate limit (3 attempts per hour, locked for 1 hour after exhaustion)
3. Hash provided code with Argon2id
4. Call repo.VerifyAndUseRecoveryCode — iterates stored hashes, uses constant-time comparison
5. On match: reset password, update SVR keys, create new session, return result
6. On mismatch: increment attempt counter, return error

NOTE: Since Argon2id uses random salt, you can't just hash the input and compare. You must use VerifyPassword against each stored hash. The repository method should load all unused code hashes and verify against each.
