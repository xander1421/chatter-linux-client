Where RecoveryResult is:
```rust
pub struct RecoveryResult {
    pub user_id: String,
    pub device_id: u32,
    pub remaining_codes: i32,
}
```

Flow:
1. Validate new PIN (6 digits)
2. Derive new_password_hash from new_password (SHA256, matching existing pattern)
3. Derive new SVR keypair from new_pin + username → get public_key_bytes
4. Derive new registration_lock from new_pin + username
5. Call auth_client.use_recovery_code()
6. Zeroize all intermediates
7. Return RecoveryResult

After recovery succeeds, the user can login with their new password + new PIN, and SVR backup can be created via retry_svr_backup.
